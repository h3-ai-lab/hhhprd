# 项目 Workflow

继承 [PRD 2.0](../../../shared/workflows/prd-2.0.md)。

补充检查：

- 推荐关系绑定与权益发放必须拆成两个阶段：先绑定关系，后由业务事件自动发放，不新增审批节点。
- 关系只使用 C 用户 ID 精确关联，且必须校验活动新注册、业务线和推荐唯一性。
- 绑定后展示 C 当前归属 CC；只有原 CC 重新分配线索给 A 后，关系才进入可发奖状态。
- 首课完课、首次购买和社媒状态事件分别作为独立奖励触发来源。
- 推荐人、被推荐人、业务事件、操作 CC、归属 CC、奖励规则和权益流水必须可相互追溯。
- 奖励事件必须先创建零金额赠送订单，再由订单驱动权益开通；订单和权益都必须使用同一幂等键。
- 统一列表、指标、详情和后续导出使用同一关系集合、日期字段和去重口径。
- C 端自动绑定、第三方社媒结果自动抓取和缺失历史关系回补不属于本版。
