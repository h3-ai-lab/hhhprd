# REQ-ORG-001：页面与功能影响评估

> 用途：按当前 CRM 的页面和功能逐项枚举账号与权限优化带来的操作、数据归属和可见性影响，用于评审范围、识别依赖和拆分版本。

## 1. 角色口径

| 角色 | 功能边界 | 数据授权依据 |
|---|---|---|
| 超级管理员 | 全局配置与全部业务模块 | 内置全部业务线 |
| 业务线经理 | 授权业务线的组织、成员、销售和看板管理 | 成员账号中的业务线数据授权 |
| 主管 | 授权节点内的成员、线索和看板管理 | 成员账号中的节点及下级授权 |
| CC | 本人线索、外呼、跟进及角色配置允许的转派动作 | 本人及主组织公共池 |

角色名称不自动产生数据范围。一个人的功能动作由唯一功能角色决定，业务线范围由成员的多条业务线数据授权决定。

## 2. 当前功能清单

## 3. 数据归属影响矩阵

| 功能编号 | 写入对象 | 本需求后的归属规则 | 历史处理 |
|---|---|---|---|
| SYS-01 | 业务线根组织 | 新增业务线形成新的根节点和数据边界 | 不影响其他业务线 |
| SYS-02 | 组织 ID、父子关系和完整路径 | 后续业务记录使用新组织路径 | 不改写已发生事件 |
| SYS-03 | 功能角色、业务线授权、主组织 | 决定之后可操作范围和新线索默认归属 | 不自动扩大历史授权 |
| SALE-01 | 线索归属人、当前业务归属 | 领取线索归属领取入口所在组织 | 保留领取事件 |
| SALE-02 | 外呼、跟进、预约 | 继承线索当前业务归属 | 保存事件时组织快照 |
| SALE-05 | 线索归属人、当前业务归属 | 分配或转派后更新到目标组织 | 保留原归属人和组织 |
| SALE-06 | 线索归属人、公共池组织 | 进入当前业务线对应组织池 | 保留退回原因和历史 |
| SALE-07 | 导入线索的业务线和组织 | 按导入配置写入唯一当前归属 | 不根据线索归属人的当前组织倒推历史 |
| USER-01 至 USER-03 | 用户展示关系 | 不改变用户主数据，只限制关联可见性 | 历史关系不删除 |
| ORDER-01 至 ORDER-02 | 业绩组织快照 | 按支付时线索运营归属统计 | 调岗和组织调整不重算 |
| DASH-01 至 DASH-06 | 聚合和导出结果 | 当前数据用当前组织，过程数据用事件快照 | 保留历史统计时点 |
| BI-01 / API-01 | 下游组织维度 | 输出业务线、当前组织、线索归属人和事件快照 | 不回写源系统 |

| 功能编号 | 超管 | 业务线经理 | 主管 | CC | 额外限制 |

| SYS-02 | 全部组织 | 授权业务线子树及必要祖先 | 授权节点子树及必要祖先 | 无 | 祖先只用于定位，只读 |
| SYS-03 | 全部成员 | 授权业务线成员 | 授权节点成员 | 无 | 组织和人员候选按字段用途及当前可访问对象计算 |
| SALE-01 至 SALE-04 | 全部 | 授权业务线 | 授权节点子树 | 本人及主组织池 | 搜索和详情同范围 |
| USER-01 至 USER-03 | 全部 | 关联有权业务线用户 | 关联有权节点用户 | 本人关联用户 | 搜索候选同步过滤 |
| ORDER-01 至 ORDER-02 | 全部 | 业务线订单 | 节点订单 | 本人订单 | 导出需独立权限 |
| CALL-01 | 全部 | 业务线通话 | 节点通话 | 本人客户通话 | 录音需独立权限 |
| DASH-01 至 DASH-06 | 全部 | 业务线汇总 | 节点汇总 | 个人汇总 | 下钻和导出不得扩大范围；导出按角色权限 |
| MKT-01 | 按业务线配置权限 | 按现有业务线授权 | 无整线配置权 | 无 | 节点数据权限不扩大配置权 |
| BI-01 / API-01 | 全部 | 授权业务线 | 授权节点 | 本人范围 | 不得绕过 CRM 权限 |

### 4.1 筛选项与人员候选范围

| 页面场景 | 候选范围 | 明确不包含 |
|---|---|---|
| 组织、成员和授权配置 | 当前操作人可管理的组织、成员和角色 | 无权管理的兄弟节点及人员资料 |
| 销售中心组织筛选 | 当前可访问线索中出现的组织及必要祖先 | 无可访问线索的无关节点 |
| 销售中心首位 CC 筛选 | 当前可访问线索中出现过的首位 CC，可包含其他组织节点人员 | 该 CC 在当前操作范围外的其他线索和客户资料 |
| 销售中心当前 CC 筛选 | 当前可访问线索中出现过的当前线索归属人 | 统计结果中未出现且无权限的成员 |
| 分配、领取和转派目标 | 有动作权限、有效主组织且符合操作组织范围的成员 | 仅因出现在筛选结果中而自动成为转派目标 |
| 管理看板当前 CC 筛选 | 当前聚合范围内出现的当前线索归属人 | 统计范围外的 CC |
| 管理看板首位 CC 筛选 | 当前聚合范围内出现的首位 CC，可包含其他节点的历史首位 CC | 该 CC 在统计范围外的其他数据 |
| 用户、订单、通话搜索 | 通过当前可访问业务对象建立关联的人员 | 仅凭姓名、手机号或用户 ID 搜索出的无权对象 |

首位 CC 筛选不扩张人员数据权限。候选可以来自其他节点，但只证明这些 CC 在当前可访问线索的首位 CC 字段中出现过，不能打开其个人资料或其他客户数据。

## 5. 业务流影响

| 流程 | 触发 | 关键影响 |
|---|---|---|
| Leads 入库 | 渠道、导入或注册进入 CRM | 写入业务线和当前组织；不确定组织时进入业务线待分配池 |
| 自动分配 | 命中业务线和组织分配规则 | 线索归属人和当前归属同时写入，后续作业继承 |
| 公共池领取 | CC 或主管领取 | 归属领取入口组织 |
| 转派 | 任意开通“转派线索”动作权限的角色操作 | 更新线索归属人和当前归属，保留历史事件 |
| 主组织变更 | 管理员修改成员主组织 | 选择直接带走或留在原组织自动分配 |
| 组织调整 | 改名、换上级、停用、合并或拆分 | 保存前展示成员、线索和规则影响并要求原因；历史仍使用快照 |
| 账号停用/离职 | 账号状态变更 | 访问立即失效，名下线索按交接流程处理 |
| 导出 | 用户下载数据 | 使用当前筛选和组织范围；导出权限独立 |

## 6. 受影响页面与入口

| 入口 | 必改内容 |
|---|---|
| 系统配置 → 组织架构 | 组织树、业务线新增、组织新增编辑、祖先只读 |
| 系统配置 → 成员账号 | 功能角色唯一、业务线多选、逐业务线授权、主组织、调岗选择 |
| 系统配置 → 角色权限 | 角色数据范围移出；只保留功能权限 |
| 系统配置 → 操作日志 | 增加业务线、组织和授权变更记录 |
| 销售中心 | 组织筛选、归属组织展示、列表及操作范围 |
| 用户中心 | 用户列表、详情、搜索和导出范围 |
| 订单中心 | 订单列表、详情、退款/续费和导出范围 |
| 通话记录 | 列表、详情、录音、文字稿范围 |
| 管理看板 | 组织筛选、汇总、下钻和导出 |
| 营销中心 | 配置权限继续以业务线为主 |
| 导入/导出 | 默认组织、候选范围、导出范围和审计 |
| 数仓/BI/API | 对齐同一组织和权限口径 |

## 7. 版本切分

| 版本 | 范围 | 发布门槛 |
|---|---|---|
| V1 配置底座 | 业务线、组织树、成员多业务线授权、主组织、角色功能权限、操作日志、存量账号映射、权限影子对比 | 完成配置和差异验证，不切换线上客户数据权限 |
| V2 权限切换 | 销售中心、用户中心、订单中心、通话、搜索、筛选候选、看板、下钻、导入导出、历史兼容 | 所有客户数据入口在同一次切换中生效 |
| V3 管理增强 | 批量调岗、批量交接、组织合并/拆分辅助、权限差异修复工具 | 沿用 V2 权限模型 |

V2 无法按页面拆成多次灰度上线，否则会出现一个模块已收紧、另一个入口仍可越权访问的漏洞。

## 8. 未单独设页面的影响

| 影响项 | 规则 |
|---|---|
| 筛选候选 | 按页面、字段和当前可访问业务对象分别计算；首位 CC 可包含其他节点的历史值，但不扩大数据权限 |
| 搜索 | 不能通过手机号、用户 ID、姓名搜索到无权客户 |
| 字段权限 | 手机号、录音、附件等继续独立控制 |
| 导出权限 | 查看权限不自动等于导出权限；能否导出由功能角色中的导出权限决定 |
| 审计 | 记录业务线、组织、成员授权、主组织变更和调岗处理 |
| 历史数据 | 不按当前组织倒推或重算 |
| 离职账号 | 禁止新业务，历史线索归属人和组织保持可追溯 |
| 外部入口 | API、BI、分享链接不得绕过 CRM 数据范围 |
