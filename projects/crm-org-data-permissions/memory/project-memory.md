# 组织与数据权限 Memory

## Confirmed Facts

- 业务线是组织树根节点，组织最多四级。
- 同一业务线内，一个成员只有一个功能角色、一条数据授权和一个主组织。
- 线索只保留一个当前业务归属节点。
- 外呼、跟进和成交保存事件发生时组织快照。
- “本业务线全部”不包含其他业务线。

## Decisions

- 组织负责人不自动获得数据、转派或配置权限。
- 人员调岗不自动迁移已有线索，必须显式交接。
- 数据范围仅由成员账号的数据授权决定。
- 历史已结束数据不按当前组织重算。

## Glossary

- 组织快照：事件发生时保存的组织 ID、名称和完整路径。
- 主组织：成员在业务线内的行政归属。
- 当前业务归属：线索当前负责的唯一组织节点。
