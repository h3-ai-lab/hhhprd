# 组织与数据权限 Memory

## Confirmed Facts

- 业务线是组织树根节点，组织最多四级。
- 一个成员只有一个功能角色，可同时授权多条业务线；每条业务线分别配置一条数据授权和一个主组织。
- 线索只保留一个当前业务归属节点。
- 外呼、跟进和成交保存事件发生时组织快照。
- “本业务线全部”不包含其他业务线。
- “本人”只含当前负责人为本人账号的线索及直接关联数据；公共池领取另行受功能角色和主组织控制。

## Decisions

- 本期不配置组织负责人；业务线、组织表单和列表均不展示负责人字段。
- 人员调岗不自动迁移已有线索，必须显式交接。
- 主组织变更时，如名下有对应业务线线索，由当前操作人选择“直接带走”或“留在原组织自动分配”。
- 更换上级、合并或停用组织前，必须展示成员、线索、规则影响并填写原因。
- 数据范围仅由成员账号的数据授权决定。
- 历史已结束数据不按当前组织重算。

## Glossary

- 组织快照：事件发生时保存的组织 ID、名称和完整路径。
- 主组织：成员在每条业务线内的唯一行政归属。
- 当前业务归属：线索当前负责的唯一组织节点。
