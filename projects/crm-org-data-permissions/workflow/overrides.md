# 项目 Workflow

继承 [`PRD 2.0`](../../../shared/workflows/prd-2.0.md)。

补充检查：

- 验证四级组织限制、业务线多选、逐业务线主组织和数据授权边界。
- 验证线索单归属、历史组织快照和人员调岗交接。
- 验证销售、用户、订单、通话、看板和导出使用同一数据范围。
- 验证页面与功能影响矩阵覆盖操作、数据归属、数据可见性和版本切分。
- 验证更换上级、合并和停用均展示影响预览，原因必填且写入操作日志。
- 验证“本人”范围只含本人当前负责线索及直接关联数据，不静默包含公共池。
- 验证“本业务线全部”可配置给业务线管理员，且与跨全部业务线的全局范围分开。
- 验证功能矩阵只表达示例配置，CC 转派由角色动作权限决定。
- 验证组织表单、列表、权限规则中不存在组织行政责任角色配置。
- 验证 PRD 不包含角色功能变更示例，角色模块按现有功能权限管理。
- 验证首位 CC、当前 CC、组织配置、转派和看板筛选分别使用场景化候选范围。
- 验证 CC 导出按角色导出权限判定，不设置固定默认关闭。
