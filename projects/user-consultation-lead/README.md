# 用户顾问咨询预约沉淀为线索跟进节点

客户端用户成功提交顾问电话咨询申请后，CRM 保存预约事实，并在用户中心与销售中心统一展示、筛选和导出，避免销售只在独立意向列表中查看。

## 本版边界

- 以客户端成功提交的顾问咨询申请作为事实源。
- 用户中心与销售中心展示同一份预约事实。
- 不改变现有邀请页、注册、Onboarding、销售阶段和线索归属规则。
- `已预约` 仅表示申请成功，不表示已接通、已安排具体上课时间或已完成咨询。
