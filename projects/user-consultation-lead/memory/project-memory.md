# 用户顾问咨询预约项目 Memory

## Confirmed Facts

- 客户端在越南新注册流程中允许用户主动申请顾问电话咨询。
- 现有独立页 `意向用户列表` 已能查询历史咨询申请，并保存提交时间。
- 当前 `意向用户列表` 没有预约来源字段。
- 销售中心已有一个名为 `销售咨询预约` 的筛选器；本需求不覆盖其现有含义。
- 用户中心和销售中心当前列表没有排序入口。

## Decisions

- 直接使用现有意向用户记录的提交时间，不新建设备、来源或预约事件模型。
- 用户中心与销售中心新增 `用户预约时间` 一个字段。
- 预约时间不为空视为 `已预约`，为空视为 `未预约`，不单独存储状态字段。
- 预约记录以 `user_id` 关联 CRM 用户；同一用户多条记录展示最新提交时间。
- 保留现有 `销售咨询预约`，新增字段用于区分用户主动申请回电。
- 不新增排序、跟进阶段自动流转或人工修改预约状态的入口。

## Glossary

- 用户预约时间：现有意向用户记录中的提交时间。
- 已预约：用户的预约时间不为空。
- 未预约：用户的预约时间不存在或为空。
