# 用户顾问咨询预约项目 Memory

## Confirmed Facts

- 客户端在越南新注册流程中允许用户主动申请顾问电话咨询。
- 成功提交后，用户进入 Onboarding，预约不改变体验课进度或上课提醒。
- 原需求要求 CRM 记录用户、联系电话、申请时间和申请来源。
- 现有独立页 `意向用户列表` 已能查询历史咨询申请，列表无排序入口。
- 销售中心已有一个名为 `销售咨询预约` 的筛选器；本需求不覆盖其现有含义。

## Decisions

- 采用独立预约事实记录，不把布尔字段作为唯一事实源。
- 用户中心与销售中心新增 `用户咨询预约`，状态由预约记录派生。
- `已预约` 仅表示用户成功提交顾问电话咨询申请，不表示已接通或已完成咨询。
- 预约记录以 `user_id` 关联 CRM 用户；销售列表按同一 `user_id` 展示，不按线索分表复制预约事实。
- 保留现有 `销售咨询预约`，新增字段用于区分用户主动申请回电。
- 现有意向用户记录按可核验的用户 ID 和提交时间回填；缺失来源显示“历史数据”。
- 不新增排序、跟进阶段自动流转或人工修改预约状态的入口。

## Glossary

- 用户咨询预约：用户从客户端主动提交并由 CRM 成功确认的顾问电话咨询申请。
- 提交意向时间：CRM 首次确认该申请创建成功的时间，不是销售联系或通话时间。
- 有效预约记录：用户、申请标识和成功确认时间均可核验的预约事实。
