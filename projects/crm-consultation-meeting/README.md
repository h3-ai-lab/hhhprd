# Lark咨询会议与用户详情回写

销售可为当前跟进阶段为“已预约”的用户创建飞书咨询会议，将会议链接发送给用户，并在会议结束后根据飞书参会事实自动更新跟进阶段，同时保存飞书生成的妙计原文。

## 本版边界

- 企业公共账号创建会议，销售本人作为会议 Owner 主持。
- 仅当前跟进阶段为 `已预约` 的用户显示创建会议入口。
- 待开始会议支持修改时间或删除；实际时长为 0 时不自动变更跟进阶段。
- 系统判定与 CC 确认一致时共用一条跟进记录，不一致时保留系统记录并新增 CC 修正记录。
- CRM 只保存飞书生成的妙计原文和链接，不重新总结，不提取试课结果或用户意向。
- 飞书会议结束事件先进入结果判断；非 Owner 参与者累计在会超过 1 分钟时自动将跟进阶段更新为 `咨询已完成`，未出勤时自动更新为 `未出勤`。
- 会议结束后向会议 Owner CC 发送包含系统出勤结果的 Lark 互动卡片；H5 默认展示结果，CC 可确认或修改。
- 有效结果为未出勤时，必须补充未出勤原因；同时可填写可选跟进说明。
- 未出勤原因固定为八类，H5 不允许修改会议出勤结果或跟进阶段。
- 系统出勤判定和 CC 有效出勤结果分开保存，修改出勤结果会记录审计。
- 跟进说明复用现有客户跟进记录，不建立独立文本数据源。
- 企业会议套餐、并发和妙计权益是上线前置条件。
