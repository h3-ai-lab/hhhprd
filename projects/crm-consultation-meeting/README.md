# Lark咨询会议与用户详情回写

销售可为当前跟进阶段为“已预约”的用户创建飞书咨询会议，将会议链接发送给用户，并在会议结束后根据飞书参会事实自动更新跟进阶段，同时保存飞书生成的智能纪要原文。

## 本版边界

- 企业公共账号创建会议，销售本人作为会议 Owner 主持。
- 仅当前跟进阶段为 `已预约` 的用户显示创建会议入口。
- CRM 只保存飞书生成的智能纪要原文和链接，不重新总结，不提取试课结果或用户意向。
- 飞书会议结束事件先进入结果判断；非 Owner 参与者累计在会超过 1 分钟时自动将跟进阶段更新为 `咨询已完成`，未出勤时自动更新为 `未出勤`。
- 企业会议套餐、并发和智能纪要权益是上线前置条件。
