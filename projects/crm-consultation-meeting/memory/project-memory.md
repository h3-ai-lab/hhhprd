# Lark咨询会议项目 Memory

## Confirmed Facts

- 销售中心筛选字段名为 `当前跟进阶段`，列表字段名为 `跟进阶段`。
- `用户状态`、`销售咨询预约` 和 `当前跟进阶段` 是三个不同字段。
- `销售咨询预约=已预约` 只表示用户存在预约时间，不等于会议已完成或当前跟进阶段为 `已预约`。
- 现有产品需求记录已包含 `咨询已完成` 阶段。
- 飞书会议结束事件包含 `meeting_id`、`calendar_event_id`、开始时间和结束时间。
- 智能纪要生成事件包含 `note_id`、纪要文档标识、逐字稿标识和来源会议 ID。
- 会议结束不保证已生成智能纪要；纪要生成也不代表客户已出勤。

## Decisions

- 本期只在 `当前跟进阶段=已预约` 时提供创建会议入口。
- 企业公共账号作为日程组织者，销售个人作为会议 Owner。
- 会前先绑定 CRM 用户、线索、日程 ID 和会议链接；会议开始后再补全会议 ID。
- 以会议结束事件触发参会结果判断，以结束后的参与人快照计算客户出勤。
- 出勤只按本次会议链接中的非 Owner 参与者累计在会时长判断：大于 1 分钟为 `已出勤`，其余为 `未出勤`。
- 不设置 `待确认` 状态，不提供销售人工确认出勤结果的入口。
- 客户有效出勤且会议正常结束后，若当前阶段仍为 `已预约`，自动更新为 `咨询已完成`。
- 未出勤时将当前跟进阶段更新为 `未出勤`，会议参会结果同步记录为 `未出勤`，并生成销售跟进提醒。
- 会议结束后无论系统判定已出勤还是未出勤，都通过 Lark 互动卡片进入 CRM H5 确认结果；链接携带用户 ID、会议 ID、系统结果和签名令牌。
- H5 默认使用系统判定结果，CC 可以修改为另一出勤状态；系统原始判定不被覆盖。
- 未出勤原因固定为学校考试、学业忙、设备问题、网络问题、家长忙、忘记预约、无法联系、学生不喜欢学习。
- H5 同时提供可选跟进说明，说明写入现有客户跟进记录，不新增独立文本字段。
- H5 不修改出勤判定和跟进阶段，原因任务按 `user_id + meeting_id` 唯一。
- H5 修改有效出勤结果时，仅当当前阶段仍是系统自动写入的阶段，才同步切换 `咨询已完成 ↔ 未出勤`。
- 确认任务按 `user_id + meeting_id` 唯一；有效结果和系统判定分别记录。
- CRM 只保存飞书智能纪要的原文快照、链接和来源标识，不进行二次总结或意向分析。
- 会议结束、纪要生成和会议链接相关字段不加到销售列表默认列，不新增列表筛选和排序。
- 企业会议套餐和纪要权益未确认时不得上线。

## Glossary

- 出勤：客户通过本次用户的唯一会议链接进入会议，并累计在会不少于 1 分钟。
- 咨询已完成：客户有效出勤且会议正常结束。
- 未出勤：会议正常结束，但没有识别到客户有效参会；同时作为会议结果和当前跟进阶段。
- 纪要待生成：会议已结束，但尚未收到飞书智能纪要生成事件。
