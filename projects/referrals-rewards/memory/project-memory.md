# 推荐奖励项目 Memory

## Confirmed Facts

- 本期范围仅限泰国业务线。
- 好友首次试听奖励邀请人 14 天。
- 好友购买 3/6/12 个月分别奖励 1/2/3 个月。
- 社媒有效投稿奖励 5 天；官方选中奖励 2 个月，未选中奖励 15 天。
- 奖励发放必须经过权益服务确认。

## Decisions

- 奖励不发现金、优惠券或积分。
- 退款只冲正对应购买奖励，不撤销试听奖励。
- 推荐关系和奖励事件都必须幂等。

## Glossary

- 邀请人：发起推荐或分享内容的泰国有效会员。
- 奖励事件：由试听、购买或社媒审核触发的权益变更来源。
- 冲正：退款成立后按规则扣回未来会员时长。
