## 本版范围

- 用户列表、销售列表和用户详情增加学习计划、当前课程进度、本周进度、最近学习时间和学习活跃状态。
- 管理看板新增“学习进度”页签，展示学习计划、活跃学习、零学习、课次完成和到期预警。
- 区分学习计划、课程体系、周学习安排、Learning Cycle 和 Lesson，避免把商业方案与课程内容混为一谈。
- Play 不计入有效学习；体验课不计入正式主课进度。

## 现状证据边界

CRM 页面现状来自 2026-11-10 的已归档页面快照；课程结构来自 Heidi Kong 转发的产品指南和课程原始资料；业务目标与学习计划口径来自与 Luca Tran 的沟通记录。正式开发前需在实际 CRM 和学习系统再次核对字段与权限。
