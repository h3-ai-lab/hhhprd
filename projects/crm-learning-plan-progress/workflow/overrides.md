# 项目 Workflow

继承 [`PRD 2.0`](../../../shared/workflows/prd-2.0.md)。

补充检查：

- 学习计划只表示用户购买的有期限方案，不表示 Level、Unit 或 Lesson 的数量。
- 周学习安排按学习计划发放每周主课额度，Pro 为 3 节/周，Max 为 5 节/周。
- 课程结构固定为 Level → Unit → Learning Cycle → Lesson，体验课与 Play 不进入正式主课进度。
- 用户列表、销售列表和用户详情使用同一学习状态、课程位置和周进度口径。
- 管理看板的学习进度指标与列表状态使用同一用户范围、时间窗口和去重键。
- 正在上课只采用课程系统明确返回的实时在课状态，不用最近学习时间推断。
- 有效学习包含 Class、Practice、Explore，不包含 Play。
- 列表新增字段明确排序结论；学习计划、课程进度、学习状态和到期预警筛选复用现有权限。
- 离职或调岗不改变用户学习数据，线索交接沿用现有销售归属规则。
