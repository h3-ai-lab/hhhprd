# 已付费列表调整正式课等级

> 在销售中心“已付费”列表的“更多”操作中增加“调整正式课等级”，沿用“修改试听课等级”的单字段弹窗交互。

| 项目编号 | 状态 |
|---|---|
| REQ-LEVEL-001 | 待上传 |

| 入口 | 用途 |
|---|---|
| PRD | 字段、交互、数据影响和权限定义 |
| 交互原型 | 已付费列表、更多菜单、正式课等级弹窗和中英文切换 |

## 项目定位

一线销售在已付费列表中直接调整用户的正式课等级。正式课等级与试听课等级相互独立；调整只影响当前正式课定级和后续课程使用，不改写试听课记录、历史学习记录、订单或会员有效期。
