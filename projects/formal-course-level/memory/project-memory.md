# 已付费列表调整正式课等级 Memory

## Confirmed Facts

- 销售中心“已付费”列表当前列顺序为：勾选、用户 ID、学生姓名、购买意向、用户状态、用户类型、年龄段、课程等级、登录账号、渠道来源-落地页、操作。
- 行操作区现有“拨号”和“更多”；“更多”当前包含试听课报告、更新跟进、重新分配线索、添加会员时长。
- 现有试听课等级使用独立弹窗：标题带用户 ID，必填等级选择器，底部为取消和保存。
- 正式课程 Level 共 L1–L6。

## Decisions

- 在“更多”菜单中新增“调整正式课等级”，位置在“更新跟进”之后、“重新分配线索”之前。
- 调整正式课等级沿用试听课等级弹窗的交互结构，但标题、字段和写入对象均为正式课等级。
- 正式课等级与试听课等级相互独立。
- 保存后只更新用户当前正式课等级；不改写历史课程、学习记录、试听课等级、订单、会员有效期和付款信息。
- 已付费列表继续展示“课程等级”列，该列显示当前正式课等级。
- 当前列表没有排序能力，本需求不新增排序。
