# CRM经营闭环规划

> 以“CC 知道今天处理谁、为什么、下一步做什么；管理者知道团队卡在哪、谁需要帮助、什么问题在重复”为主旨，规划 CRM 从销售执行到管理干预的整体能力。

| 入口 | 用途 |
|---|---|
| [管理层汇报](https://h3-ai-lab.github.io/hhhprd/projects/crm-operating-closure/briefing/) | 用于领导与业务负责人汇报 |
| [规划 PRD](https://h3-ai-lab.github.io/hhhprd/prd-crm-operating-closure.html) | 目标、业务流程、阶段、指标、权限与数据边界 |
| [交互原型](https://h3-ai-lab.github.io/hhhprd/projects/crm-operating-closure/prototype/) | 查看 CC 今日行动与管理经营摘要的产品形态 |

## 项目定位

本项目是 CRM 经营能力的整体规划，不是单一页面需求。后续销售、回访、预约、PL、回款和学习履约需求均应映射到本项目的能力地图中，明确所属角色、业务阶段、前置事件、下一步动作和目标指标。

## 交付物

| 目录 | 内容 |
|---|---|
| `prd/` | 单文件规划 PRD |
| `prototype/` | CC 与管理者双角色工作台原型 |
| `briefing/` | 面向领导和业务负责人的五页汇报 |
| `memory/` | 已确认事实、决策和术语 |
| `rag/` | 资料来源 |
