## 项目定位

本项目聚焦 CC 在销售中心内的快捷筛选：系统根据现有跟进、外呼、预约、体验课、咨询、PL 和订单数据，计算每个线索的唯一主工作队列。今日新注册高意向待接通与历史未联系待接通是两个独立队列，不做合并。本期不新增页面、菜单、持久化队列字段或独立任务中心。

更高层的 CRM 经营闭环规划已拆分为独立规划项目，不再作为本项目下的附属汇报入口。
