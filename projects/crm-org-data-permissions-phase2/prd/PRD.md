## 目标与范围

**目标**

- CC 的正常列表只展示本人线索，但能看到本人线索下由其他成员产生的全部跟进、通话、预约和任务。
- 首次 CC 筛选、重新分配和转派目标可以出现其他成员，但不得因此扩大普通客户数据权限。
- 管理者按授权组织子树或整条业务线查看线索、关联记录、看板和导出。
- 线索、跟进、通话、用户、订单和业绩继续保存事件时组织快照，用于组织归属和历史统计。

**做**

- 在成员账号中按业务线配置“本人 / 指定组织及下级 / 本业务线全部”。
- 将数据权限接入销售、用户、订单、通话、看板、搜索、候选、导入和导出。
- 区分普通数据范围、动作处理范围和历史候选引用。
- 建立线索、跟进、通话、预约、任务和订单之间的访问继承关系。
- 迁移当前业务归属，保持历史数据不反推。

**不做**

- 不修改角色功能权限和既有动作权限项。
- 不支持一条线索同时归属多个组织。
- 不建设跨组织业绩分摊或复杂协作贡献。
- 不按人员当前组织改写已结束业绩。
- 不新增看板页签或导出格式。

## 前置条件

- 一期业务线、组织树和成员主组织已完成配置并核对。
- 每条在职成员的业务线均存在有效主组织。
- 当前账号实际业务线权限和团队关系可导出，用于生成新旧权限差异。
- 销售、用户、订单、通话、看板、搜索和导出具备同时切换条件。

## 核心模型

| 概念 | 作用 | 边界 |
|---|---|---|
| 功能角色 | 决定菜单、页面和动作权限 | 本需求不修改角色功能 |
| 数据授权 | 决定本人、组织子树或整条业务线的普通数据范围 | 不决定字段可见性和导出 |
| 主组织 | 人员产生新业务数据时的默认组织归属 | 不决定人员可以查看哪些数据 |
| 线索归属人 | 当前处理线索的成员账号 | 允许多次变化，分配历史必须保留 |
| 当前业务归属 | 线索当前承接组织 | 线索只保留一个当前归属 |
| 事件组织快照 | 业务事件发生时的组织 ID、名称和完整路径 | 组织调整后不回写 |
| 访问关系 | 当前账号通过本人线索、本人操作、组织授权或业务关联访问对象 | 不替代业务归属和组织快照 |

## 数据授权

成员账号在每条业务线下按以下顺序配置：

`业务线 → 数据授权 → 主组织`

| 数据范围 | 普通数据范围 | 主组织默认值 |
|---|---|---|
| 本人 | 本人当前或历史作为线索归属人的线索，以及这些线索关联的全部跟进、通话、预约、任务、用户和订单；本人作为操作人的事件也可查看 | 保留已选主组织；未选择时要求手动选择 |
| 指定组织及下级 | 可多选组织节点，覆盖所选节点及其后代；不包含业务线根节点直属数据和兄弟节点 | 保留已选主组织或由管理员选择 |
| 本业务线全部 | 业务线根节点直属数据、全部现有下级和未来新增下级 | 自动默认业务线根节点，可调整 |

规则：

- “本业务线全部”只覆盖当前选中的业务线；跨所有业务线属于独立全局能力。
- 同一业务线内多条授权取并集，不同业务线分别判断。
- 数据授权不改变主组织，主组织也不自动扩大数据授权。
- 成员未配置有效主组织时可以查看已有授权数据，但不能接收新分配线索。
- 查看、编辑、分配、转派、导出分别校验。

## 访问关系模型

二期不能只用“线索归属人”或“组织节点”一个条件判断所有页面，需要区分以下范围：

| 范围 | 定义 | 可以访问 | 不可以访问 |
|---|---|---|---|
| 本人主对象 | 本人当前或历史作为线索归属人的线索 | 线索列表、详情、个人 Dashboard、关联用户和订单 | 其他成员线索和公共池 |
| 本人线索关联记录 | 挂在可访问线索下的业务事件 | 该线索的全部跟进、通话、预约、任务和附件，即使由其他人产生 | 其他不可访问线索下的记录 |
| 组织范围 | 数据授权包含的业务线或组织子树 | 范围内线索、关联记录、团队看板和明细 | 范围外节点及其数据 |
| 动作处理范围 | 分配、重新分配或转派时，用于选择源线索和目标人员的作业范围 | 源线索、目标成员的姓名、组织和处理所需信息 | 扩大普通列表、详情、Dashboard、用户中心或导出 |
| 历史候选引用 | 首位 CC 等历史字段在当前可访问线索上的去重值 | 作为筛选值或身份引用 | 被引用人员的其他线索、资料和业务数据 |

判定顺序：

`账号状态 → 功能权限 → 页面主对象范围 → 关联记录继承 → 动作处理范围或历史候选引用 → 字段与导出权限`

## 组织树权限

组织树既是导航结构，也是数据授权边界，必须单独校验页面内可见和可操作范围。

| 能力 | 规则 |
|---|---|
| 可见节点 | 当前操作人每个数据授权节点的完整子树，加上从授权节点到业务线根节点的必要祖先路径 |
| 祖先节点 | 只用于展开、定位和理解路径，只读展示；不产生成员、线索、看板或子节点编辑权限 |
| 可编辑节点 | 仅限操作人明确授权节点及其下级；无权节点不能编辑、启用、停用或新增下级 |
| 父节点候选 | 更换上级时，只能选择同业务线、当前可管理、非自身及自身后代、且不突破四级的节点 |
| 成员主组织候选 | 只能选择当前操作人可管理业务线中的节点；必要祖先不可选 |
| 数据授权节点候选 | 只能选择当前操作人可管理节点；“指定组织及下级”可从所选节点开始多选 |
| 批量转移目标 | 只能是同业务线且位于当前操作人可编辑范围内的节点 |
| 非连续授权 | 例如授权 A 部和 B 部时，只展示两棵子树及各自根路径，不自动包含中间的兄弟部门 |

角色边界：

- 超级管理员可以查看和管理全组织树。
- 业务线管理员可以查看和管理被授权业务线的组织树。
- 区域/部门主管只能查看和管理授权节点子树；无权上级和兄弟节点不会因出现在路径中被赋予操作能力。
- 普通 CC 不进入组织树配置，只使用主组织和业务线权限完成个人作业。

## CC 视角

CC 通常配置“本人”。普通列表和详情只展示本人线索；动作工作区和筛选候选可以出现其他人员，但不改变普通数据权限。

| 功能 / 场景 | CC 可见范围 | 关联记录与操作边界 |
|---|---|---|
| 销售中心线索列表、我的线索、已付费 | 本人当前或历史线索 | 不显示同组其他成员负责的线索 |
| 公海、待领取 | 主组织允许领取的未分配线索 | 领取后线索归属人变为本人，才进入本人线索范围 |
| 线索详情 | 可访问线索的基础资料、阶段、归属历史和操作入口 | 线索可见即展示该线索完整操作历史 |
| 跟进记录 | 可访问线索下的全部跟进 | 包括其他 CC 或管理员添加的跟进 |
| 通话记录、录音、文字稿 | 可访问线索产生的全部通话 | 包括其他成员对该线索发起的通话；录音和文字稿继续校验字段权限 |
| 预约、待办、跟进任务 | 可访问线索关联的全部任务和预约 | 他人创建的任务可见；编辑按动作权限判断 |
| 首位 CC 筛选 | 可访问线索中出现过的首位 CC，可包含其他节点人员 | 只作为筛选值，不打开该人员其他数据 |
| 当前 CC 筛选 | 当前可访问线索中出现过的当前线索归属人 | 不能搜索枚举未出现且无权限的 CC |
| 重新分配源线索 | 有重新分配功能权限时，可选择主组织动作范围内的线索，可包含同组其他 CC 的线索 | 仅用于重新分配，不进入普通列表、用户中心或导出 |
| 重新分配目标 CC | 同业务线、动作范围内、启用且具备接收能力的 CC | 只展示姓名、组织和可用状态等必要信息 |
| Dashboard | 本人线索、本人执行行为和本人线索关联结果 | 不包含同组其他人的工作量或团队汇总 |
| 用户中心 | 通过本人可访问线索或订单关联的用户部分 | 不能按手机号或姓名搜索出其他成员的用户 |
| 订单、退款、续费 | 本人可访问线索关联的订单 | 其他成员订单不可见 |
| 导入 | 有导入动作权限时，写入本人主组织动作范围 | 不能借导入读取其他组织已有客户 |
| 导出 | 当前列表或功能范围与角色导出权限的交集 | 动作处理范围中的他人线索不自动允许导出 |
| 操作日志 | 普通 CC 不进入操作日志页面 | 可访问线索的分配历史和业务事件在线索详情中展示 |

## 管理视角

管理者使用“指定组织及下级”或“本业务线全部”。记录可见性先由线索主对象确定，再继承该线索下的全部关联记录。

| 功能 / 场景 | 管理者可见范围 | 关联记录与操作边界 |
|---|---|---|
| 销售中心列表、线索详情、已付费 | 授权组织子树或整条业务线内线索 | 可按组织、当前 CC、首位 CC、状态和时间筛选 |
| 公海、待领取 | 授权组织下的公共池 | 只在组织和分配规则范围内操作 |
| 跟进、通话、预约、任务 | 授权范围内线索关联的全部记录 | 不限制记录操作人，可查看团队成员产生的记录 |
| 首位 CC / 当前 CC 筛选 | 范围内线索中的实际字段值；首位 CC 可跨节点引用 | 候选出现不等于获得该人员其他数据权限 |
| 分配、重新分配、转派 | 源线索在管理范围内；目标成员在动作允许的组织范围内 | 跨节点操作按功能权限和审计要求执行 |
| Dashboard | 授权节点子树或整条业务线 | 可切换“团队数据”和“本人数据”；本人视图只保留当前操作人数据 |
| 用户、订单、通话、下钻 | 与授权范围内线索关联的部分 | 汇总、下钻和导出使用同一底层数据范围 |
| 组织、成员和操作日志 | 授权组织内配置和日志 | 必要祖先只用于定位，不产生数据或编辑权限 |
| 导入、导出 | 当前管理范围与动作权限的交集 | 导入不能扩大已有客户读取范围 |

## 页面与功能可见性矩阵

| 页面 / 功能 | CC（本人） | 管理者（组织范围） | 关键规则 |
|---|---|---|---|
| 线索主列表 | 本人线索 | 授权范围内线索 | 先确定主对象范围 |
| 线索详情 | 可见线索 | 范围内线索 | 直链同权限 |
| 跟进记录 | 可见线索的全部跟进 | 范围内线索的全部跟进 | 继承父线索，不看记录操作人 |
| 通话记录 | 可见线索的全部通话 | 范围内线索的全部通话 | 录音字段权限独立 |
| 重新分配 | 功能开启时，主组织动作范围内源线索 | 管理范围内源线索 | 动作范围不等于普通查看范围 |
| 转派目标 | 动作范围内其他 CC 身份 | 授权范围内其他 CC 身份 | 只提供必要候选信息 |
| 首位 CC 筛选 | 可见线索中出现过的其他节点人员 | 范围内线索中出现过的人员 | 历史引用不扩大数据权限 |
| Dashboard | 本人数据 | 团队范围，可切换本人 | 汇总、下钻、导出同范围 |
| 用户中心 / 订单中心 | 本人线索关联对象 | 授权范围线索关联对象 | 不以共享用户主键扩大范围 |
| 搜索 | 本人线索及关联对象 | 授权范围线索及关联对象 | 搜索结果同列表权限 |
| 导出 | 当前范围 ∩ 导出权限 | 当前范围 ∩ 导出权限 | 动作候选不自动可导出 |

### 组织层级筛选

- 销售中心不保留“业务线”和“组织架构”两个并列筛选器，统一为一个组织树筛选器。
- 业务线是一级根节点；选择整条业务线等价于按该业务线边界筛选，选择具体区/部/组等价于按该组织子树筛选。
- 普通 CC 的组织树筛选只展示其有业务线权限的根节点，用于切换业务线；不会因选择根节点而扩大到组内其他 CC 的线索。
- 管理者的组织树筛选展示其数据授权内的业务线根节点和组织节点。
- 当前 CC 候选只来自所选组织范围与当前账号可访问线索的交集。
- 首跟 CC 候选来自当前结果中实际出现过的历史首跟 CC，可跨组织节点，但不会扩大客户数据权限。
- 业务线或组织切换后，原 CC 筛选值如不在新候选中自动清空。

- 管理者只展示与授权组织范围线索或订单关联的用户部分。
- 共享用户 ID 不能成为跨组织扩大可见范围的依据。
- 手机号、短信验证码等敏感字段继续使用独立字段权限。

### 其他顶层入口

订单中心必须按订单关联线索、订单事件时组织和当前数据授权判断；用户列表、订单列表和团队监控中的业务线筛选统一升级为组织树筛选。

权限要求：

- 首跟 CC 筛选

- 首跟承接量、首跟覆盖率、外呼次数、接通次数及外呼接通率
- 首跟 CC 生产力汇总表

权限要求：

- 首跟 CC 可以跨组织节点出现，但只作为统计维度，不扩大其客户数据权限。
- 导出当前视图使用当前筛选条件、统计范围与导出权限交集。

## 筛选项与人员候选

| 页面场景 | 候选范围 | 明确不包含 |
|---|---|---|
| 组织、成员、授权组织和主组织选择 | 当前操作人可管理的组织、成员和角色 | 无权管理的兄弟节点及人员资料 |
| 销售中心组织筛选 | 当前可访问线索中实际出现的组织及必要祖先 | 无可访问线索的无关节点 |
| 销售中心首位 CC 筛选 | 当前可访问线索中出现过的首位 CC，可包含其他节点人员 | 该 CC 在其他节点负责但当前操作人无权的线索和资料 |
| 销售中心当前 CC 筛选 | 当前可访问线索中出现过的当前线索归属人 | 结果中未出现且无权限的成员 |

| 分配、领取和转派目标 | 有动作权限、有效主组织且符合操作组织范围的成员 | 仅因出现在筛选结果中而成为目标 |
| 管理看板当前 CC | 当前聚合范围内参与统计的当前线索归属人 | 统计范围外的 CC |
| 管理看板首位 CC | 当前聚合范围内出现过的首位 CC | 该 CC 在范围外的其他数据 |
| 用户、订单、通话搜索 | 通过当前可访问业务对象建立关联的人员 | 仅凭姓名、手机号或用户 ID 搜索出的无权对象 |

| 自动分配 | 目标成员 | 分配规则目标组织 | 记录分配事件 |
| 公海领取 | 领取人 | 领取入口所属组织 | 记录领取事件 |

### 事件记录字段

| 数据对象 | 必须记录 | 用途 |
|---|---|---|
| 线索 | 业务线、当前归属组织、当前线索归属人、分配历史 | 当前列表、本人关系和管理范围 |
| 跟进、通话、预约、任务 | 关联线索 ID、操作人 ID、事件时间、事件时组织快照 | 继承线索访问、个人行为筛选和团队历史统计 |
| 用户、订单 | 关联线索、业务线、事件时组织、关键归属人快照 | 关联数据可见性和业绩归属 |

组织记录节点继续成立，但不能作为唯一可见性判断条件。可见性采用“父对象范围 → 关联记录 → 可选操作人条件”：

- CC 先取得本人线索，再查询这些线索下的全部跟进和通话。
- 管理者先取得授权组织内线索，再查询这些线索下的全部关联记录。
- 需要“只看我执行的”时，再追加记录操作人=当前账号条件。

## 组织调整与人员调岗

- 组织更换上级、批量转移成员或停用前展示成员、线索、分配规则和组织节点影响，并要求填写原因。
- 修改人员某条业务线主组织时，如名下有对应业务线线索，保存前必须提示处理方式。
- “直接带走”：保留当前线索归属人，将对应业务线线索的当前业务归属更新为人员新主组织；历史事件和组织快照不回写。
- “留在原组织自动分配”：线索业务归属不变，原线索归属人清空，按原组织规则重新分配；无接收人时进入原组织待分配池。
- 账号停用后立即失去登录、分配、领取、查询和导出权限。
- 历史线索归属人、组织路径、作业和业绩保持原快照，并展示“已停用”。

## 历史与切换

- 以正式切换时间区分旧一级业务线权限和新组织数据权限。
- 切换前导出账号实际业务线范围，映射为逐业务线数据授权并生成差异。
- 无法确认权限时默认不扩大范围，由管理员人工确认。
- 当前仍有效的线索、用户、订单和通话，按切换时可确认的归属人和主组织建立当前业务归属。
- 已结束线索、通话、跟进和订单不批量倒推组织。
- 当前归属无法确认时保留业务线级或进入业务线待分配池。
- 销售、用户、订单、通话、搜索、候选、看板、下钻和导出必须同时切换。

## 异常与边界

| 场景 | 处理 |
|---|---|
| 组织超过四级 | 禁止新增或移动 |
| 同一上级组织重名 | 禁止保存 |
| 跨业务线移动根节点 | 禁止 |
| 成员无有效主组织 | 可查看已有授权数据，不进入新线索分配候选 |
| 成员仅部分业务线有数据授权 | 只对应业务线生效 |
| 首位 CC 在其他组织节点 | 可作为筛选项，但不获得其他数据权限 |
| CC 在重新分配中看到同组他人线索 | 仅动作处理场景可见，不进入普通列表、Dashboard、用户中心或导出 |
| 线索可见但记录操作人不同 | 跟进、通话、任务等正常可见；编辑和敏感字段按动作及字段权限判断 |
| 组织停用 | 停止新增成员、授权和分配；历史数据保留 |
| 权限撤销 | 下一次请求立即生效，列表、详情、下钻和导出同步收紧 |
