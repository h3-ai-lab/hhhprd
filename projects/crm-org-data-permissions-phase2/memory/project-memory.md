# 组织数据权限二期 Memory

## Confirmed Facts

- 一期已完成业务线、组织树和人员主组织的配置。
- 二期基于第一期组织配置启用数据授权，不重新定义组织架构。
- 功能角色和动作权限继续沿用现有配置。
- 跟进、通话、预约和任务继承父线索的访问范围。

## Decisions

- CC 普通列表只看当前归属为本人的线索；线索转派后原归属人失去该线索及关联记录。
- 本人线索下的全部跟进、通话、预约和任务均可见，不按记录操作人二次收窄。
- 公共池按业务线根节点共享，同一业务线内有访问权限的成员均可查看，领取能力另行校验。
- 首位 CC 可以作为跨节点筛选值，但不扩大该人员其他数据权限。
- CC 的重新分配源线索只包含本人当前线索；即使拥有重新分配功能，也不能选择同组其他 CC 的线索。
- 重新分配目标 CC 可选同业务线下所有启用、具备有效主组织和接收能力的人员，不要求位于当前数据授权节点。
- 管理者按授权组织范围查看团队数据，并可切换本人数据视图。
- 组织树筛选支持搜索、多选和父节点覆盖下级；必要祖先仅用于定位且不可勾选。
- 组织树默认展开当前主组织所在业务线及祖先路径，其他分支保持收起。
- 组织、首位 CC、当前 CC 筛选互相联动；依赖值失效时自动清空。
- 数据产生时的组织节点继续用于归属和历史统计，但不是唯一访问条件。
- 访问判断还需关联线索 ID、线索归属历史和记录操作人。

## Glossary

- 本人线索：当前线索归属人为本人的线索。
- 关联记录：挂在可见线索下的跟进、通话、预约、任务和附件。
- 动作处理范围：管理者的重新分配源线索，以及分配、重新分配和转派的目标候选范围；CC 重新分配源线索始终等于本人线索范围。
- 历史候选引用：首位 CC 等历史字段在可访问线索上的去重值。
