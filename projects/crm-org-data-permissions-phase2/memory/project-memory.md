# 组织数据权限二期 Memory

## Confirmed Facts

- 一期已完成业务线、组织树和人员主组织的配置。
- 二期基于第一期组织配置启用数据授权，不重新定义组织架构。
- 功能角色和动作权限继续沿用现有配置。
- 跟进、通话、预约和任务继承父线索的访问范围。

## Decisions

- CC 普通列表只看本人线索；本人线索下的全部跟进、通话、预约和任务均可见，不按记录操作人二次收窄。
- 首位 CC 可以作为跨节点筛选值，但不扩大该人员其他数据权限。
- 重新分配使用独立动作处理范围；CC 在功能开启时可以处理主组织动作范围内的同组他人线索，但不得扩大普通列表、Dashboard、用户中心或导出。
- 管理者按授权组织范围查看团队数据，并可切换本人数据视图。
- 数据产生时的组织节点继续用于归属和历史统计，但不是唯一访问条件。
- 访问判断还需关联线索 ID、线索归属历史和记录操作人。

## Glossary

- 本人线索：本人当前或历史作为线索归属人的线索。
- 关联记录：挂在可见线索下的跟进、通话、预约、任务和附件。
- 动作处理范围：分配、重新分配或转派时用于选择源线索和目标人员的作业范围。
- 历史候选引用：首位 CC 等历史字段在可访问线索上的去重值。
