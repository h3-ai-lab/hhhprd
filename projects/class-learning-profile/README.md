# 班级学习画像看板

> 面向班主任与年级管理角色，汇总班级学习表现、知识点掌握、学生分层和待关注学生。

| 项 | 内容 |
|---|---|
| 状态 | 待评审 |
| 需求编号 | REQ-CLP-001 |
| 正式 PRD | [PRD](prd/PRD.md) |

## 本版范围

- 班级概览与四项核心指标。
- 知识点掌握分析与学生名单下钻。
- 四类学生分层及人数、占比。
- 待关注学生识别、查看、标记已关注与导出。
- 学生详情页。
