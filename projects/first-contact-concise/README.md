# 引入首跟节点&首跟看板-2

本项目用于验证“评审版 PRD + 研发详表”的双层文档结构。

| 文档 | 使用者 | 用途 |
|---|---|---|
| [PRD.md](PRD.md) | 产品、业务、评审人员 | 快速理解目标、范围、流程、页面变化和权限结论 |
| [DETAILS.md](DETAILS.md) | 研发、测试、AI | 查询完整字段、排序、筛选顺序、权限矩阵、数据依赖和异常规则 |
| [线上原型](https://h3-ai-lab.github.io/hhhprd/projects/first-contact/prototype/) | 所有角色 | 查看上线后的真实操作界面 |

## 文档优先级

- `PRD.md` 是业务决策源。
- `DETAILS.md` 只展开实现所需细节，不产生第二套业务结论。
- 两份文档内容冲突时，先修订 `PRD.md`，再同步 `DETAILS.md`。
- 两份文档共用同一个需求编号和版本号。

## AI 使用顺序

1. 先读取 `PRD.md` 确认目标、边界和产品决策。
2. 只在需要字段、规则、权限或异常细节时读取 `DETAILS.md`。
3. 原型只用于确认交互和页面结构，不反向替代 PRD 的业务规则。
