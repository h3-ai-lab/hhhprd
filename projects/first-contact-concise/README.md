# 引入首跟节点&首跟看板-2

本项目是单文件 PRD 设计规范的正式参考样例，同时服务需求评审、研发理解和 AI 开发。

| 入口 | 用途 |
|---|---|
| [PRD](prd/PRD.md) | 目标、规则、字段、排序、指标口径、RBAC、数据和异常 |
| [线上原型](https://h3-ai-lab.github.io/hhhprd/projects/first-contact-concise/prototype/) | 查看上线后的实际操作界面 |

## 使用原则

- `prd/PRD.md` 是唯一业务决策源。
- 指标定义、原型展示和研发理解必须使用同一口径。
- 原型只用于确认交互和页面结构，不反向替代 PRD。

## 项目结构

| 目录 | 内容 |
|---|---|
| `workflow/` | 指标冻结和一致性检查扩展 |
| `skills/` | 公共 Skill 使用说明 |
| `rag/` | CRM 与首跟需求来源清单 |
| `memory/` | 已确认指标、规则和术语 |
| `prd/` | 单文件 PRD |
| `prototype/` | 专属交互原型 |

## AI 使用顺序

1. 读取 `prd/PRD.md` 确认目标、边界、指标、字段、权限和异常规则。
2. 使用原型核对页面结构和交互呈现。
3. 发现指标名称、分子、分母或值与 PRD 不一致时，先修订 PRD 并同步原型。
