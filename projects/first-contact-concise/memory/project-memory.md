# 首跟-2 项目 Memory

## Confirmed Facts

- 首次成功分配写入首跟节点，后续事件不覆盖。
- 首次外呼、首次接通和累计次数按事件去重。
- 线索人数类指标按 Lead ID 去重，次数类指标按 Call ID 去重。
- 当前销售中心列表没有排序能力，所有字段不支持排序。

## Decisions

- 指标放在团队监控，不新增独立看板页签。
- 每个指标展示分子和分母，并提供“口径”角标。
- 原型只展示上线后的产品页面。
- PRD 保持单文件，不再拆分研发详表。

## Glossary

- 首跟覆盖率：首跟 CC 非空线索数 ÷ 筛选范围内全部线索数。
- 首次外呼覆盖率：首次外呼线索数 ÷ 首跟线索数。
- 首次接通覆盖率：首次接通线索数 ÷ 首跟线索数。
