# 外呼能力一期

> 管理可用主叫号码，在拨号时按业务线、并发和被叫频次选择号码；通话记录展示实际主叫号码，并支持把当前筛选结果与录音、逐字稿按 `call_id` 组织为可追溯的批量导出包。

## 本版范围

- 新增 `系统管理 → 外呼管理 → 号码池管理`，维护号码、供应商、线路、可用业务线、状态、并发和被叫频次限制。
- 供应商与线路使用后端固定枚举，一期不提供供应商或线路配置页。
- 通话记录新增“主叫号码”，记录实际成功分配的外显号码。
- “下载数据”增加“是否导出录音”选项，默认否；选择是时生成包含结果清单、录音索引和逐条文件目录的 ZIP。

## 关键定位规则

录音和逐字稿统一以 `call_id` 作为唯一业务键。每个通话使用独立目录 `files/{call_id}/`，索引文件保存每个文件在导出包内的精确相对路径；不得依赖姓名、手机号、起呼时间或文件名拼接来定位。

## 项目结构

| 目录 | 内容 |
