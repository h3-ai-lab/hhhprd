# 外呼能力一期 Memory

## Confirmed Facts

- 外呼与线路由智齿、Omicall 等第三方承担，CRM 负责号码选择、承接、记录和配置。
- 通话记录现有列为起呼时间、用户 ID、姓名、手机号、通话结果、时长、录音、文字稿、本次跟进记录。
- 现有通话记录页签没有可排序表头。
- 录音可能同步中，文字稿可能暂不可用。

## Decisions

- 号码池入口放在系统管理下的外呼管理，一期仅系统管理员和超级管理员可按业务线维护。
- 供应商固定为智齿、Omicall；线路使用后端固定枚举，不提供配置页面。
- 号码创建后不可改号码本身；需更换号码时停用旧号码并新增新号码。
- 通话记录在手机号后插入主叫号码，不改变其他现有列的相对顺序。
- 录音批量导出使用一个 ZIP，以 `manifest.csv` 和 `call_id` 目录共同定位文件。
- 普通数据导出与录音、逐字稿批量导出使用不同权限。
