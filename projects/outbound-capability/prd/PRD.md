## 目标与范围

**目标**

统一维护主叫号码、供应商、线路、适用业务线和状态；同时让通话记录可追溯到实际主叫号码，并使运营能够按一次筛选结果稳定定位和批量下载录音与逐字稿。

**做**

- 新增 `系统管理 → 外呼管理 → 号码池管理`。
- 维护号码、供应商、线路、适用业务线和状态。
- 支持下载 CSV 模板、校验预览和批量导入号码。
- 在现有通话记录“手机号”后增加“主叫号码”。
- 在“下载数据”中加入“是否导出录音”，默认否。
- 选择导出录音时，按 `call_id` 将当前结果数据、<del>[原] 录音和逐字稿</del> <ins>[现行] 已生成的录音和已生成的逐字稿</ins>组织为一个 ZIP，并生成可定位每个文件的索引。
- <del>[原] 大范围导出使用后台任务，进度弹窗可关闭，用户可在“导出任务”中继续查看进度、取消或下载。</del> <ins>[现行] 大范围导出使用后台任务，创建后直接进入“导出任务”，支持查看状态、取消和下载。</ins>

**不做**

- 不新增供应商、线路的配置管理页面；两项均使用后端固定枚举。
- 不改写第三方电话连接、录音生成和逐字稿转写能力。
- 不把录音数量、录音缺失数包装成经营指标。
- 不在未选择“导出录音”时下载录音或逐字稿。
- <ins>[新增] 批量导出不触发生成逐字稿，只下载导出开始前已经存在的逐字稿。</ins>

## 现状与证据边界

本次线上 CRM 页面未能在开发环境中再次建立受控读取，以下通话记录现状来自 2026-11-10 已核对的运行截图和现有操作手册，属于非实时辅助证据：

`起呼时间 → 用户ID → 姓名 → 手机号 → 通话结果 → 时长 → 录音 → 文字稿 → 本次跟进记录`

现有筛选顺序为：

- 第一行：搜索、业务线、通话结果、外呼坐席邮箱。
- 第二行：开始时间、结束时间、重置、下载数据。

截图中的表头没有排序入口，本需求不新增排序能力。号码池为新页面，本期同样不提供排序能力。

## 需求 1：号码池管理

### 页面与交互

入口：`系统管理 → 外呼管理 → 号码池管理`。

- 默认展示当前数据权限内的号码列表、搜索和筛选区。
- 默认列为：`号码 → 供应商 → 线路 → 适用业务线 → 状态 → 操作`。
- 操作提供“编辑”和“停用 / 启用”。不提供硬删除。
- `+ 新增号码`打开表单；点击行内“编辑”打开同一表单并带入当前值。
- `批量导入`打开导入对话框，支持下载模板、选择 CSV、校验预览、导入有效行和下载失败行。
- 保存成功后刷新当前页和对应行，并展示号码与状态。
- 无数据、无权限、加载失败和筛选无结果使用不同提示。

### 字段与排序

| 字段 | 业务含义 | 类型与枚举 | 必填 / 默认值 | 来源与编辑规则 | 异常展示 | 排序结论 |
|---|---|---|---|---|---|---|
| 号码 | 用于识别和追踪的主叫号码 | E.164 电话号码 | 必填，无默认值 | 管理员创建；创建后只读 | 格式错误或重复时阻止保存 | 不支持；新页面不提供排序能力 |
| 所属供应商 | 号码归属的供应商 | 供应商1、供应商2、供应商3 | 必填，无默认值 | 从后端固定枚举选择；不可新增或改名 | 无可用枚举时禁用保存 | 不支持；新页面不提供排序能力 |
| 线路 | 号码使用的线路 | 线路1、线路2、线路3 | 必填，无默认值 | 从后端固定枚举选择；不可新增或改名 | 无可用枚举时禁用保存 | 不支持；新页面不提供排序能力 |
| 适用业务线 | 该号码归属的业务线 | 马来西亚、越南、泰国，可多选 | 必填，至少一项 | 管理员维护 | 无选择时阻止保存 | 不支持；新页面不提供排序能力 |
| 状态 | 该号码在 CRM 中的启用或停用标记 | 启用、停用 | 必填，默认启用 | 管理员可切换 | 无权限时只读 | 不支持；新页面不提供排序能力 |

供应商和线路只管理号码上的选择值，不管理枚举本身，两者分别使用后端固定枚举，不建立页面上的供应商与线路联动。

### 规则

| 场景 | 规则 | 结果 |
|---|---|---|
| 新增号码 | 去除空格后统一为 E.164；号码全局唯一 | 保存成功；重复号码不能保存 |
| 编辑基本信息 | 号码本身不可编辑；供应商、线路、适用业务线和状态可修改 | 保存成功后更新当前记录 |
| 停用 | 更新 CRM 中的号码状态 | 当前记录显示停用；历史通话不回写 |
| 重新启用 | 更新 CRM 中的号码状态 | 当前记录显示启用 |
| 元数据编辑 | 供应商、线路和适用业务线可修改 | 历史通话保留当时快照 |

### 批量导入

- 下载模板后填写一行一个号码；模板列为：`号码、所属供应商、线路、适用业务线、状态`。
- 适用业务线使用 `马来西亚|越南|泰国` 形式填写；状态使用“启用”或“停用”。
- 选择文件后先展示总行数、有效行数、无效行数和逐行校验结果，不直接写入。
- 文件头缺失或整体格式错误时阻止预览；行级错误只影响该行。
- 用户确认后导入全部有效行，无效行跳过；导入完成后提供失败行 CSV。
- 文件内重复号码以后出现的行标记错误；已存在于号码池的号码标记错误。
- 重复点击导入只处理一次；相同文件和内容不会重复写入。

### 列表行为

- 通话记录默认列和筛选区仍使用现有布局；在“手机号”后插入主叫号码列，在“业务线”后插入主叫号码筛选。
- 搜索范围扩大到主叫号码，支持完整号码和连续号码片段。
- 分页、页签切换和筛选组合与现有通话记录一致。
- 主叫号码显示完整号码；是否允许导出仍受通话记录导出权限控制。
- 同一号码在号码池后续停用或编辑，不改变历史通话中的主叫号码。

## 需求 3：批量导出录音与逐字稿

### 下载入口与选项

入口：`销售管理 → 销售中心 → 通话记录 → 下载数据`。

- 点击“下载数据”先打开导出对话框。
- <ins>[新增] 导出配置对话框只在创建任务前出现；任务创建后不再通过弹窗展示进度、完成结果或下载入口。</ins>
- 对话框展示当前筛选条件、结果行数、已接通行数、可定位录音组数和缺失文件数。
- “是否导出录音”复选框默认不勾选。
- 未勾选时沿用普通结果数据导出，不读取录音或逐字稿。
- 勾选后展示导出包结构说明，并在用户确认后创建异步导出任务。
- <ins>[新增] 逐字稿只读取已经生成的文件；缺失时不调用转写服务，也不阻塞整个导出任务。</ins>
- 导出范围是当前筛选条件下的全部结果，不受当前分页限制。
- 通话记录操作区提供“导出任务”入口；有处理中任务时显示任务数量。
- <del>[原] 创建任务后展示可关闭的进度弹窗，用户关闭后可从导出任务继续查看进度。</del> <ins>[现行] 创建任务后关闭配置对话框并直接进入“导出任务”，不展示实时进度弹窗。</ins>

### 文件组织

一次录音导出生成一个 ZIP。ZIP 内固定包含：

```text
manifest.csv
call-records.csv
files/
  {call_id}/
    recording.{extension}
    transcript.{extension}
```

- `call_id` 是通话唯一业务键，也是录音组目录名。
- 每个通话使用独立目录，避免同一被叫号码多次接通时文件互相覆盖。
- `recording` 与 `transcript` 使用固定逻辑文件名，真实扩展名由供应商返回类型决定。
- `manifest.csv` 每条通话记录一行，写明文件在 ZIP 内的相对路径或缺失原因。
- `call-records.csv` 保存与页面相同筛选范围的结果数据，并包含主叫号码。
- ZIP 文件名格式：`outbound_recording_{business_line|ALL}_{yyyyMMddHHmmss}_{task_no}.zip`。

### 索引定位

`manifest.csv`至少包含：

`export_row_no、call_id、user_id、business_line、callee_number、caller_number、call_started_at、call_result、recording_path、transcript_path、asset_status、missing_reason`

| 状态 | 条件 | 导出包处理 |
|---|---|---|
| `BOTH_AVAILABLE` | 录音和逐字稿均可下载 | 两个文件进入对应 `call_id` 目录 |
| `RECORDING_ONLY` | 只有录音可用 | 导出录音，逐字稿路径留空并说明原因 |
| `TRANSCRIPT_ONLY` | 只有逐字稿可用 | 导出逐字稿，录音路径留空并说明原因 |
| `SYNCING` | 第三方仍同步中 | 保留记录行，不阻塞整包；标记同步中 |
| `UNAVAILABLE` | 供应商明确不可用 | 保留记录行，标记不可用 |
| `NO_CALL_ID` | 历史记录缺少唯一定位号 | 不生成文件目录；标记历史记录缺少定位号 |
| `NOT_CONNECTED` | 通话未接通 | 不要求录音组；只保留普通结果行 |

只有文件实际取得后才写入对应路径。不得用姓名、手机号或起呼时间拼接目录名，也不得用供应商原始文件名直接覆盖同名文件。

### 导出任务

<ins>[新增] 本期“导出任务”只承载通话记录导出；后续演进为全站通用导出任务时沿用该任务中心入口。</ins>

| <del>[删除] 关闭进度弹窗</del> | <del>[删除] 仅关闭当前弹窗，不取消后台任务；用户可以继续浏览或离开当前页面</del> | <del>[删除] 任务继续处理，可从“导出任务”重新进入</del> |

| 打包失败 | 不生成空包或部分包 | 任务失败，可重试 |
| 权限撤销 | 未下载任务停止并可清理；已下载文件不追回 | 下次请求失效 |
| 超过上限 | <del>[原] 单次超过 5,000 条已接通通话时阻止创建</del> <ins>[现行] 单次超过 5,000 条通话记录时阻止创建；不设置单批次文件大小上限</ins> | 提示缩小日期或筛选范围 |

<del>[原] `任务编号、创建时间、导出范围、结果行数、任务状态、处理进度、更新时间、操作`</del>

## 数据依赖与一致性

| 数据 / 系统 | 来源 | 唯一标识 | 时效与失败处理 |
|---|---|---|---|
| 号码池 | CRM 外呼管理配置 | 标准化主叫号码 | 保存后更新当前记录；失败不改变原配置 |
| 供应商与线路枚举 | 后端固定枚举 | 枚举代码 | 前端只读；枚举加载失败时不能保存号码 |
| 批量导入 | 管理员上传的 CSV 与校验结果 | `import_no` + 文件内容 | 校验通过后导入有效行；失败行可在结果中下载 |
| 通话记录 | 第三方外呼回写 | `call_id` | 延迟时保留已有快照；重复回写不新增记录 |
| 主叫号码快照 | 通话建立时第三方回写的主叫号码 | `call_id` | 号码池后续编辑不覆盖 |
| 录音 | 第三方同步 | `call_id` | 可能同步中、不可用或延迟；不阻塞通话记录 |
| 逐字稿 | 第三方转写 | `call_id` | 可能同步中、不可用或延迟；不阻塞通话记录 |
| 导出任务 | CRM 导出服务 | `task_no` | 失败重试沿用原筛选快照；不同任务使用不同批次号 |

## 异常与边界

- **无数据**：号码池显示“暂无号码”，不把无权限或加载失败显示为空数据。
- **重复号码**：按 E.164 标准化后全局唯一，重复提交返回原号码并提示已存在。
- **批量导入文件错误**：文件头缺失或文件整体格式错误时阻止预览；行级错误只拒绝对应行。
- **批量导入部分成功**：有效行导入，失败行不写入；结果展示成功数和失败原因，并可下载失败行 CSV。
- **重复导入**：相同文件内容重复提交不产生重复号码；已在号码池或文件前序行出现的号码标记失败。
- **第三方回写延迟**：通话记录未取得 `call_id` 前保留处理中状态；取得后补齐录音组定位。
- **重复通话事件**：按 `call_id` 去重，重复回写返回原结果。
- **录音同步中**：通话记录正常展示，导出计划中标记 `SYNCING`；<ins>[新增] 单个录音或逐字稿不可用时不阻塞整个任务，任务完成后仍未就绪则写入缺失原因。</ins>
- **历史通话缺少主叫号码**：显示 `—`，不使用当前号码池倒推。
- **历史通话缺少 call_id**：不生成录音目录，索引标记 `NO_CALL_ID`。
- **导出权限被撤销**：未完成任务停止，已生成链接在下次请求失效。
- **权限变化**：菜单、数据范围、字段和导出在下次请求生效。
