# 项目 Workflow

继承 [`PRD 2.0`](../../../shared/workflows/prd-2.0.md)，主类型为表单、字段与列表，补充规则状态数据和集成自动化。

补充检查：

- 主叫号码在号码池中唯一，存储前统一为 E.164 格式。
- 通话记录保存实际主叫号码快照，号码后续编辑不改变历史通话。
- 号码池只维护号码、供应商、线路、适用业务线和状态，不包含选号策略。
- 录音与逐字稿以 `call_id` 定位，导出索引必须保存文件在 ZIP 内的精确相对路径。
- 导出使用当前筛选结果而非当前分页；录音包与普通数据导出权限分开。
- 导出任务在后台执行，创建后直接进入任务中心；关闭浏览器或离开页面不终止任务。
- 任务中心只展示任务状态、记录总数和预计完成时间，不展示进度条或已处理条数，支持取消与完成下载。
- 文件缺失、同步中和无逐字稿必须进入索引状态，不静默跳过，也不阻塞整个任务。
- 导出只读取已经生成的逐字稿，不因导出主动触发转写；单次最多 5,000 条通话记录，不限制文件大小，文件有效期为 7 天。
- 导出包只允许任务创建者在当前仍有导出权限时下载，不提供外链分享。
- 本期任务中心只承载通话记录导出，后续再演进为全站通用导出任务。
- CSV 批量导入必须先校验预览；有效行与失败行分别统计，失败行可下载。
- 供应商与线路分别使用固定枚举，不建立页面联动或配置管理。
- 所有号码配置、状态变更和录音导出记录审计。
