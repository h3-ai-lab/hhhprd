## 页面策略

- 不新增菜单、页面或工作台。
- 在 `销售管理 → 销售中心 → 分配与掉库设置` 内增加配置。
- 配置面板使用“分组规则 / 销售权重 / 掉库规则”三个页签，避免把不同设置堆在同一屏。
- 新增和编辑单条渠道规则使用面板内联表单，不再叠加二级弹窗。

## 本版边界

- 按稳定渠道标识匹配，每个业务线内同一渠道只能配置一条规则。
- 目标小组复用 REQ-ORG-002 的多选组织树交互，可一次选择多个组。
- 目标小组范围确定后，沿用现有销售权重在合并候选中分配。
- 销售权重表增加只读主组织列，并支持按主组织搜索、多选筛选。
- 所选小组均没有合格销售时，线索进入业务线待分配池。
- 不改变人工领取、重新分配、转派、掉库和付费跟进规则。
- 不对已有线索批量重新分配。
