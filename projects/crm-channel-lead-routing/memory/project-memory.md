# CRM渠道线索自动分配到小组 Memory

## Confirmed Facts

- 项目依赖 REQ-ORG-002 已完成业务线、组织树、人员主组织和跨组作业数据隔离。
- 现有“分配与掉库设置”按业务线维护掉库规则、领取人和分配权重。
- 当前自动分配和掉库重分配均按业务线销售权重随机分配。
- 本需求只交付一个配置功能，不新增页面、看板、导出或模拟器。

## Decisions

- 在现有“分配与掉库设置”内增加“分组规则”，与“销售权重”“掉库规则”使用页签分隔。
- 分组规则只有渠道、目标小组和启用状态；渠道和目标小组分别支持多选，不增加规则名称、优先级或说明字段。
- 渠道使用稳定渠道 ID/Code 匹配；同一业务线内一个渠道只允许一条规则。
- 目标小组复用 REQ-ORG-002 的可搜索多选组织树，并使用只允许选择组级节点的目标小组模式。
- 先匹配目标小组范围，再从所选小组合格成员的并集中使用现有销售权重选择接收人。
- 目标小组只包含主组织直接位于所选小组的合格成员，不自动包含未选小组或下级组。
- 未匹配渠道时继续使用现有业务线分配规则。
- 所选小组均无合格销售时，负责人为空并进入业务线待分配池。
- 规则只作用于保存后新进入未分配态的线索；已有线索和已有销售归属不重新分配。
- 掉库重分配保留线索原当前业务归属小组，不重新按渠道匹配。
- 中英文切换、页签切换和业务线切换保留未保存的草稿；关闭或取消后恢复已保存配置。

## Glossary

- 渠道规则：将一个或多个稳定渠道的线索路由到同一业务线一个或多个目标小组的配置。
- 目标小组：规则命中后共同组成候选范围的组级组织节点。
- 组内分配：目标小组范围确定后，从所选小组的合格成员并集中按现有销售权重选择接收人的过程。
- 业务线待分配池：所选目标小组均没有合格接收人时，保存未分配线索的公共池。
