# CRM 线索质量分析

> 将广告渠道、活动、广告组和广告归因接入 CRM 用户中心、销售中心与管理看板，用同一批线索的接通、预约、体验和付费表现判断广告来源质量。

## 本版范围

- 用户中心、销售中心增加广告渠道、活动、广告组、广告四级筛选与只读字段。
- 管理看板“转化总览”和“销售跟进”的转化明细，在现有“先按 / 再按”中增加投放分组，并可选择四个广告层级。
- 广告层级仅使用稳定 ID 关联，名称用于展示；同一用户或线索的首次有效广告归因写入后不覆盖。
- 只使用 CRM 线索、外呼、预约、课程和订单结果，不展示投放费用、曝光、点击、CTR、CPL 或 ROAS。

## 现状证据边界

当前会话无法连接实时 CRM。页面现状基于 `crm-manual` 中 2026-11-10 的已归档页面快照和操作手册，仅用于确认字段顺序、筛选区和现有指标；正式开发前仍需在实际环境再次核对页面结构。
