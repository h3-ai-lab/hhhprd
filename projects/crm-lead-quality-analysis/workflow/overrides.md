# 项目 Workflow

继承 [`PRD 2.0`](../../../shared/workflows/prd-2.0.md)。

补充检查：

- 核对用户中心、销售中心和管理看板现有字段与筛选顺序后，再描述目标位置。
- 广告渠道、活动、广告组和广告使用稳定 ID 关联，名称只用于展示。
- 广告渠道、活动、广告组、广告分别支持多选，业务线保持单选。
- 批量分配前校验选中线索的业务线集合；跨多个业务线时阻止提交，不改变现有分配策略。
- 用户中心和销售中心展示同一份首次有效广告归因，后续广告触点不覆盖。
- 用户中心、销售中心和看板使用相同归因状态、业务线数据范围和空值规则。
- 仅在转化总览、销售跟进的转化明细“先按 / 再按”增加投放，支持四个广告层级，不新增顶部广告筛选。
- 看板每个指标均写明分子、分母、统计范围、时间字段、去重键和零分母规则。
- 用户中心、销售中心、看板的指标名称和原型数值逐项一致。
- 筛选区拥挤问题不在本期通过角色字段可见性、自定义字段或默认折叠解决。
- 离职、停用和转派不改变线索的广告归因快照，历史员工仍按现有看板规则可追溯。
- 新字段沿用现有页面查看和导出权限，不创建新的菜单或页面权限。
