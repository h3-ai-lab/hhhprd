# 暂停跟进直出结果项目 Memory

## Confirmed Facts

- `暂不跟进` 是当前跟进阶段之一，不等于退回公海、重新分配或关闭线索。
- 更新跟进入口为 `销售管理 → 销售中心 → 我的跟进 → 更多 → 更新跟进`。
- 当前跟进阶段由“下一步操作”驱动，一条线索同一时间只有一个当前阶段。
- 跟进历史和生命周期事件追加保存，不覆盖原记录。
- 暂停原因属于暂停事件；用户产生新的预约、拒绝或关闭结果后，不应丢失该暂停原因。
- 现网已允许暂停态直接恢复，并按预约历史决定可执行的终态是“已拒绝”还是“已关闭”。
- 暂停态直接新建预约仍是缺口。

## Decisions

- 暂停态开放 `恢复跟进`、`新建预约` 和当前适用的终态动作。
- `新建预约` 保存成功后直接进入 `已预约`，同一事务退出暂停状态。
- 暂停后直接预约、拒绝或关闭只记录本次真实业务动作，不补写 `恢复跟进` 事件。
- `恢复跟进` 保留，只用于没有新的预约、拒绝或关闭结果、单纯继续跟进的情况。
- 存在历史预约时，终态为 `已关闭`；从未预约过时，终态为 `已拒绝`。
- 有效预约存在时仍禁止暂停或关闭；待支付仍禁止新建预约。
- 本期不改列表字段、筛选、排序和导出。

## Glossary

- 直出结果：用户处于暂不跟进时，直接提交预约、拒绝或关闭结果，无需先提交恢复跟进。
- 隐式恢复：直出结果使线索离开暂不跟进状态，但不单独生成恢复跟进事件。
- 当前有效预约：已创建、尚未完成出勤或咨询结果处理的唯一预约。
