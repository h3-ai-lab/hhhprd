# 暂停跟进直出结果项目 Memory

## Confirmed Facts

- `暂不跟进` 是当前跟进阶段之一，不等于退回公海、重新分配或关闭线索。
- 更新跟进入口为 `销售管理 → 销售中心 → 我的跟进 → 更多 → 更新跟进`。
- 当前跟进阶段由“下一步操作”驱动，一条线索同一时间只有一个当前阶段。
- 跟进历史和生命周期事件追加保存，不覆盖原记录。
- 暂停原因属于暂停事件；用户产生新的预约、拒绝或关闭结果后，不应丢失该暂停原因。
- 现网按预约历史决定终态是“已拒绝”还是“已关闭”。
- 外呼系统可能把语音信箱识别为已接通。

## Decisions

- 系统删除 `恢复跟进` 动作及其所有新入口。
- 外呼未接通自动回写 `未接通`，不打开强制跟进弹窗。
- 外呼接通后打开跟进表单，与手动添加跟进共用同一套动作规则。
- 暂停态开放 `暂不跟进`、`新建预约` 和当前适用终态动作，默认选择 `暂不跟进`。
- `新建预约` 保存成功后直接进入 `已预约`，同一事务退出暂停状态。
- 暂停后直接预约、拒绝或关闭只记录本次真实业务动作，不补写恢复事件。
- 暂停态再次选择暂不跟进表示保持暂停并追加本次跟进，不重复暂停状态迁移。
- 存在历史预约时，终态为 `已关闭`；从未预约过时，终态为 `已拒绝`。
- 暂停原因新增 `语音信箱`。
- 有效预约存在时仍禁止暂停或关闭；待支付仍禁止新建预约。
- 本期不改列表字段、筛选、排序和导出。

## Glossary

- 直出结果：用户处于暂不跟进时，直接提交预约、拒绝或关闭结果。
- 保持暂不跟进：线索仍为暂不跟进，仅追加本次跟进说明或调整暂停原因。
- 当前有效预约：已创建、尚未完成出勤或咨询结果处理的唯一预约。
