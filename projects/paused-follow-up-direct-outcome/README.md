# 暂停跟进后直接产生跟进结果

系统移除“恢复跟进”操作。外呼未接通自动回写阶段；外呼接通和手动添加跟进都直接选择新建预约、暂不跟进或按现网规则拒绝/关闭线索。

| 项 | 内容 |
|---|---|
| 状态 | 待评审 |
| 需求编号 | REQ-FOLLOW-001 |
| 正式 PRD | [PRD](prd/PRD.md) |
| 线上原型 | [打开线上原型](https://h3-ai-lab.github.io/hhhprd/projects/paused-follow-up-direct-outcome/prototype/) |
| 需求类型 | 规则、状态与数据；补充表单交互、权限与审计 |

## 本版边界

- 调整外呼后跟进和手动添加跟进的下一步操作、阶段落库及历史口径。
- 外呼未接通不再强制打开跟进表单，自动回写 `未接通`。
- 外呼接通后和手动添加跟进共用同一套动作规则。
- 暂停后新建预约一次保存完成，不生成额外恢复事件。
- 暂停原因新增 `语音信箱`。
- 不新增列表字段、筛选器、排序能力或导出。
