# 暂停跟进后直接产生跟进结果

销售在线索处于“暂不跟进”时，可以直接新建预约、标记拒绝或关闭线索；只有没有新的业务结果、希望继续跟随时才选择“恢复跟进”。

## 本版边界

- 只调整更新跟进弹窗中“暂不跟进”状态的下一步操作和状态落库。
- 暂停后新建预约一次保存完成，不要求先恢复跟进，也不生成额外恢复事件。
- 已支持直接拒绝或关闭的业务线保持不变，本需求补齐并保护这两条路径。
- 不新增列表字段、筛选器、排序能力或导出。
