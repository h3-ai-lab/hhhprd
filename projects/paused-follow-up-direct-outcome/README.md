## 本版边界

- 调整外呼后跟进和手动添加跟进的下一步操作、阶段落库及历史口径。
- 外呼未接通不再强制打开跟进表单，自动回写 `未接通`。
- 外呼接通后和手动添加跟进共用同一套跟进项规则。
- 移除所有新入口中的 `恢复跟进` 动作。
- 暂停后可直接新建跟进，不再先恢复跟进。
- 暂停原因新增 `语音信箱`。
- 不新增列表字段、筛选器、排序能力或导出。
