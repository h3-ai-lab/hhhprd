# 项目 Workflow

继承 [`PRD 2.0`](../../../shared/workflows/prd-2.0.md)，主类型为集成与自动化。

补充检查：

- 客户端事件必须包含幂等键、业务时间和来源。
- 绑定关系、关注状态和营销授权分别维护，不使用单一“已绑定”状态代替发送资格。
- 同一 Provider 下用于绑定和发送的 LINE 用户 ID 必须一致。
- 关注、授权、归属或账号状态变化后，未发送任务不得继续执行。
- LINE 接口受理、消息送达和用户阅读必须使用不同措辞。
- Channel Access Token 和用户 Token 不进入客户端提交契约或 CRM 页面。
- 新增工作台、发送、重试、刷新和解除绑定必须逐项校验 RBAC 并记录审计。
- PRD、原型状态名称、发送按钮可用条件和失败原因必须一致。
