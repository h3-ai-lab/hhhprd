# CC活跃度看板

> 在 CRM 中复现业务方提供的 CC 销售连续性与早期预警看板，让销售管理者按业务线、团队和统计周期识别出单节奏异常。

| 主要类型 | 看板与指标 |
| 补充类型 | 权限与审计、规则状态与数据 |

## 本版方向

- 页面结构、指标名称、数据展示和风险动作完全以业务方截图为准。
- 默认复现 2026-11-09 至 2026-11-15 的 16 / 18、9 / 18、2 / 18 三项汇总结果。
- 一致性分层固定为高一致性、良好、待改善、低一致性。
- 风险状态固定为健康、早期预警、有风险、高危。
- 休息 CC 在明细表中展示为“休息”，但不进入任何指标分母。
- 本期不提供看板内规则配置、导出、个人详情或干预任务。
