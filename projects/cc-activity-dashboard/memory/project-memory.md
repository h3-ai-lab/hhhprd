# CC活跃度看板项目 Memory

## Confirmed Facts

- 项目名称为“CC活跃度看板”，需求编号为 REQ-DASH-008。
- 现有需求来自 Sales Tracking – Sales Consistency & Early Warning System 截图，目标是尽早发现 CC 出单节奏异常。
- 截图样例统计周期为 2026-11-09 至 2026-11-15，共 7 天。
- 截图中的有效样本为 18 名 CC，排除 3 名标记为 Need break 的 CC。
- 每个 CC 展示最近成交日期、连续未成交天数、平均出单间隔和最近 7 天每日成交记录。
- 汇总指标中文名称固定为近期销售活跃率、销售一致性和高风险 CC 占比。
- 平均出单间隔按“统计周期天数 ÷ 有成交的日期数”计算；7 天周期中成交 5、4、3、2、1 天分别对应 1.40、1.75、2.33、3.50、7.00 天。
- 项目需要进入 CRM，并为销售管理者提供按业务线、团队和个人查看的能力。
- 本期页面筛选顺序为业务线、销售团队、统计周期。
- 有效成交定义为支付成功、未被取消或全额退款的有效订单；以首次支付成功时间形成成交日。
- 三项汇总指标按 CC 人数去重，不能与订单笔数混用。
- 页面结构、数据展示、指标口径和风险动作完全以业务截图为准。

## Decisions

- 本期不提供页面内指标配置、导出、个人详情或主管干预任务。
- 一致性、风险阈值和指标公式按业务截图固定。
- 休息 CC 在明细表中展示为“休息”，但不进入任何指标分母。
- 已生成单文件 PRD 和中英文交互原型，项目进入待评审阶段。
- 默认统计周期为最近 7 个完整自然日，近期活跃观察窗口为 2 个完整自然日。
- 一致性门槛为高一致性 ≤ 1.75 天、良好 ≤ 2.33 天、待改善 ≤ 3.50 天。
- 风险门槛为健康 0 天、早期预警 1 天、有风险 2–3 天、高危 ≥ 4 天。

## Proposed Defaults

- 默认展示业务截图对应的 2026-11-09 至 2026-11-15。
- 近期销售活跃率观察最近 2 个完整日。
- 一致性分层为高一致性、良好、待改善、低一致性。
- 风险分层为健康、早期预警、有风险、高危。
- 高风险 CC 等同于高危状态。
- 页面中文指标名称统一为近期销售活跃率、销售一致性、高风险 CC 占比，不混用英文指标名。
- 业务截图中的 3 位休息 CC 在明细表中显示为“休息”，不进入 18 位有效 CC 分母。
- 当前版本不提供页面内配置、导出、个人详情或主管干预任务。

## Glossary

- CC：负责客户沟通、商机推进和成交的销售人员。
- 有效成交：支付成功、未取消或全额退款的有效订单首次支付成功事件。
- 成交日：某 CC 在某日内至少产生一笔有效成交；同日多笔只计一个成交日。
- 平均出单间隔：统计周期天数除以成交日数。
- 最近活跃：最近 N 个完整日内至少出现一个成交日。
- 休息：业务侧当前暂不参与销售连续性统计的 CC 状态。
