# 项目 Workflow

继承 [`PRD 2.0`](../../../shared/workflows/prd-2.0.md)。

## PRD 阶段补充检查

- 需求主类型为看板与指标；补充权限与审计、规则状态与数据。
- 先读取现有 CRM 管理看板页面及实际筛选区，再设计新增入口、筛选和指标位置。
- 每个指标写明名称、分子、分母、单位、统计范围、时间字段、去重键和零分母规则。
- 所有百分比指标统一使用 CC 人数还是业务事件次数，不得混用。
- PRD、指标配置页和原型中的指标名称、公式、筛选和去重口径必须逐项一致。
- 新增页面、配置操作和数据列表必须输出 RBAC 权限矩阵、字段与数据范围及审计要求。
- 普通数据导出默认使用 `.xls`；导出范围不得绕过当前筛选和数据权限。
- 配置规则按生效日期版本化，历史周期沿用当期规则版本，不因后续改配置而重算。
- 原型只展示看板、筛选、下钻、口径配置和导出，不加入休息审批或主管辅导任务。

## 当前排除

- Need break、请假、培训、临时停单及其自动排除。
- 预警任务、主管辅导、恢复计划和闭环跟踪。
- AI-CC 线索和知识库。
- 学习时长、留存、续费健康度等产品指标。
