# 集成与自动化类 PRD 提示词

先读取 [`prd-generation.md`](prd-generation.md)。

## 适用信号

- 广告平台、支付、课程、电话线路、IM、会员权益等外部系统进入或离开 CRM。
- 需要接收回调、定时同步、批量导入、消息通知或自动任务。
- 外部事件可能延迟、重复、乱序或失败。

## 业务契约必须回答

- 事件来源、触发条件和业务所有者。
- 进入 CRM 的业务对象和唯一标识。
- 最少业务字段、时间、业务线和幂等键语义。
- 实时、准实时还是定时同步，允许的延迟和截止时点。
- 重复、乱序、缺失、超时、部分成功和完全失败如何处理。
- 是否重试，最大次数、间隔、人工处理和对账方式。
- 外部状态撤销时如何回退本地对象。
- 历史数据是否补录，不能补录时页面如何展示。

不写接口 URL、报文实现、代码或数据库结构，只写业务事件和业务契约。

## RBAC 权限数据

集成同步或自动化任务产生用户可操作数据时，必须读取 [`04-permission-audit.md`](04-permission-audit.md)，说明：

- 外部数据归属哪个业务线和数据范围。
- 哪些角色可查看同步结果、处理失败、重试或关闭异常。
- 用户触发同步、人工重试和批量修复是否分别受权限控制。
- 本次新增、修改或复用的 RBAC 权限项。

## PRD 组织

1. 业务链路和外部依赖。
2. 事件与业务对象映射。
3. 时序、幂等、重试和补偿。
4. 页面状态、人工处理和告警。
5. 历史与数据一致性。

## 内部检查

- 外部成功是否被误当成业务最终成功。
- 重复和乱序事件是否有确定结果。
- 失败是否能被发现、重试或人工处理。
- 外部数据可见范围、人工处理和重试是否纳入 RBAC。
- 是否混入了接口实现、代码或验收。
