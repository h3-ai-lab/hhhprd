# 规则、状态与数据类 PRD 提示词

先读取 [`prd-generation.md`](prd-generation.md)。

## 适用信号

- 需要定义计算、资格判定、优先级、唯一性、超时、版本或状态转换。
- 同一对象在不同条件下有不同结果。
- 涉及退款、冲正、幂等、并发、重复事件和历史数据。

## 必须回答

- 规则由哪些输入决定，输入为空、非法或延迟时怎么处理。
- 多条规则冲突时谁优先，是否存在豁免或人工覆盖。
- 状态有哪些，进入和退出条件是什么，哪些状态不可逆。
- 唯一约束是什么，重复请求返回原结果还是创建新记录。
- 计算使用哪个时间点、时区、币种和统计口径。
- 并发修改是否需要串行、版本校验或失败重试。
- 退款、撤销、超时和历史数据造成什么补偿。

建议使用决策表：

| 输入/条件 | 判定 | 结果状态 | 异常与恢复 |
|---|---|---|---|
| | | | |

复杂需求使用状态图或状态迁移表。

## RBAC 权限数据

规则新增或状态转换入口产生新操作时，必须读取 [`04-permission-audit.md`](04-permission-audit.md)，说明：

- 哪些角色可以触发、覆盖、撤销或人工处理规则。
- 规则作用的数据范围和业务线。
- 人工覆盖、强制重试、退款冲正等敏感动作的权限与审计。
- 新增、修改或复用的 RBAC 权限项。

## PRD 组织

1. 业务规则目标和边界。
2. 对象、字段和状态定义。
3. 决策表与状态迁移。
4. 幂等、并发、超时和数据一致性。
5. 页面如何展示状态与失败原因。
6. 权限和历史兼容。

## 内部检查

- 规则是否穷尽输入范围和优先级。
- 状态是否只通过明确动作迁移。
- 重复、并发、超时和补偿是否说得清。
- 规则触发、人工覆盖和数据范围是否纳入 RBAC。
- 是否混入了开发实现、SQL、测试用例或验收。
