# 看板与指标类 PRD 提示词

先读取 [`prd-generation.md`](prd-generation.md)。

## 适用信号

- 漏斗、趋势、KPI、同比/环比、经营日报或分析看板。
- 用户需要从汇总数字下钻到明细或下载对账。
- 指标口径、数据时效或业务线范围不清楚。

## 每个指标必须写清

- 指标名称和业务用途。
- 分子、分母、去重维度和过滤条件。
- 时间字段、时区、自然日/自然月或业务周期。
- 业务线、国家、团队、角色等维度。
- 空值、取消、退款、测试用户和异常状态是否纳入。
- 数据来源、更新频率和允许延迟。
- 是否支持下钻、明细字段和导出，下钻范围必须与数字一致。
- 是否支持历史回补，回补后看板如何提示变化。

## RBAC 权限数据

新增看板、指标或明细下载时，必须读取 [`04-permission-audit.md`](04-permission-audit.md)，说明：

- 哪些角色可以进入看板、看到哪些业务线和数据范围。
- 汇总数字、明细下钻和导出是否使用相同数据权限。
- 手机号、收入、客户明细等敏感字段是否脱敏或禁止导出。
- 本次新增、修改或复用的 RBAC 权限项。

## PRD 组织

1. 业务问题和决策场景。
2. 指标定义表。
3. 筛选、维度和时间口径。
4. 汇总、趋势、漏斗和下钻。
5. 权限、数据时效和导出。
6. 待确认。

## 内部检查

- 汇总与明细使用同一过滤、去重和时间口径。
- 看板、下钻和导出使用一致的 RBAC 数据范围。
- 百分比是否来自正确的分子和分母。
- 空数据是否不会被展示为真实零。
- 是否混入查询语句、代码或验收。
