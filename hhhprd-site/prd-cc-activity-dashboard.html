CC活跃度看板

在 CRM 管理看板增加“CC销售连续性与预警”视图，帮助销售管理者识别近期没有成交、销售节奏变慢和连续未成交的 CC。
需求编号：REQ-DASH-008｜状态：待评审｜更新时间：2026-11-23
需求类型：看板与指标｜补充类型：规则状态与数据、权限与审计

交互原型

打开完整交互原型

目标与范围

目标

将业务方当前通过 Sales Tracking 表维护的 CC 销售连续性管理方式转为 CRM 看板。页面结构与数据展示以业务方提供的截图为唯一设计依据。

页面首屏默认展示业务方截图对应的 2026-11-09 至 2026-11-15 数据，并复现以下结果：

  • 近期销售活跃率：16 / 18，88.9%。
  • 销售一致性：9 / 18，50.0%。
  • 高风险 CC 占比：2 / 18，11.1%。
  • 有效 CC：18 位；休息 CC：3 位，只在明细表中展示，不进入指标分母。

做

  • 展示三项汇总指标。
  • 展示销售一致性四档分布。
  • 展示每位 CC 的最近成交日期、连续未成交天数、平均出单间隔和每日成交情况。
  • 展示风险状态及对应建议动作。
  • 支持业务线、销售团队和统计周期筛选。

不做

  • 不在页面内配置阈值、公式或指标版本。
  • 不在页面内新增、审批或修改休息状态。
  • 不提供导出、个人详情页或管理干预任务。
  • 不分析成交金额、AI-CC 对话、学习进度、续费或退费。

核心定义

定义口径
有效订单支付成功、未被取消或全额退款，且在统计截止时仍有效的订单；按订单 ID 去重
有效成交有效订单首次支付成功形成的一次成交事件
成交日同一 CC 在同一业务自然日内至少有一笔有效成交；同日多笔只计一个成交日
有效 CC 样本在所选业务线、销售团队内，岗位为 CC、状态为在岗、非测试账号的 CC；每位 CC 只计一次
休息 CC业务侧当前状态为休息的 CC；在明细表中展示，但不进入任何指标分母
平均出单间隔统计周期自然日数 ÷ 该 CC 在统计周期内的成交日数
连续未成交天数从最近有效成交日次日起至统计截止日的自然日数；周期内没有成交时，从统计周期开始日计算

销售一致性分层固定采用业务方当前口径：

分层平均出单间隔
高一致性≤ 1.75 天
良好> 1.75 天且 ≤ 2.33 天
待改善> 2.33 天且 ≤ 3.50 天
低一致性> 3.50 天或无有效成交

风险状态与建议动作固定采用业务方当前口径：

状态连续未成交天数建议动作
健康0 天保持销售节奏
早期预警1 天检查重点客户和近期预约
有风险2–3 天进行商机盘点并安排一对一辅导
高危≥ 4 天立即干预并制定恢复计划

建议动作只作为看板提示，不自动创建任务。

业务流程

flowchart LR A[订单支付成功] --> B{订单在截止时有效} B -- 是 --> C[生成成交日] B -- 否 --> D[取消或退款剔除] C --> E[按 CC 聚合成交日] U[有效 CC 样本] --> F[计算连续性指标] E --> F F --> G[CC销售连续性与预警] R[休息状态] --> H[明细展示] H -. 不进入指标分母 .-> F

页面与筛选

入口：管理看板 → CC销售连续性与预警。

筛选顺序：

业务线 → 销售团队 → 统计周期

  • 业务线默认越南，可按管理员权限切换。
  • 销售团队默认全部团队，候选范围受业务线和数据权限限制。
  • 统计周期默认 2026-11-09 至 2026-11-15。
  • 开始日期和结束日期均包含；结束日期按业务线时区的完整日截止。
  • 当前页面不提供排序入口，表格所有字段不支持排序。

筛选变化后，三项指标、一致性分布、CC 明细和风险说明使用同一业务线、团队、日期与数据权限范围。

页面结构

页面顶部依次展示：

近期销售活跃率 → 销售一致性 → 高风险 CC 占比

每张指标卡包含：

  • 中文指标名称。
  • 百分比。
  • 分子和分母。
  • “口径”角标；点击后展示分子、分母、单位、统计范围、时间字段、去重键和零值规则。

中部左侧展示“销售一致性分布”，依次为：

高一致性 → 良好 → 待改善 → 低一致性

每档展示 CC 人数、占有效 CC 样本比例和组内平均出单间隔。

中部右侧展示 CC 明细表，默认列顺序：

CC编号 → CC姓名 → 所属团队 → 连续未成交天数 → 最近有效成交日期 → 平均出单间隔 → 一致性分层 → 统计周期内每日成交标记

  • 每日列按日期升序排列。
  • 有有效成交显示 1，无成交显示“-”。
  • 活跃 CC 在指标计算后按连续未成交天数从高到低排列；休息 CC 固定展示在表格末尾。
  • 休息 CC 的连续未成交天数、最近成交日期和平均出单间隔显示“—”，一致性分层显示“休息”。
  • 无数据时展示空态，不将无数据显示为真实零。

页面底部展示“风险状态与建议动作”表，固定列出健康、早期预警、有风险、高危四档及其天数范围和建议动作。

指标具体口径

公共口径

  • 统计范围：当前筛选的业务线、销售团队、统计周期和数据权限。
  • 业务时间：以业务线时区确定自然日；开始日 00:00 包含，结束日次日 00:00 不包含。
  • 订单去重：按 order_id 去重。
  • 成交日去重：按 cc_id + 业务日期 去重。
  • 有效 CC 去重：按 cc_id 去重；休息 CC 不进入分母。
  • 零分母：显示“—”和“0 / 0”，不显示 0%。
  • 精度：百分比和平均出单间隔保留一位小数时，按业务展示统一格式；计算使用未截断值。

一致性分布

四档人数之和必须等于有效 CC 样本数。每位有效 CC 只能进入一个分层。

组内平均出单间隔：

  • 分子：组内所有有效个人平均出单间隔之和。
  • 分母：组内具有有效平均出单间隔的 CC 数。
  • 无有效值显示“—”。
