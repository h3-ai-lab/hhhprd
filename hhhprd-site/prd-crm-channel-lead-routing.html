CRM渠道线索自动分配到小组

在现有“分配与掉库设置”中分别多选渠道和目标小组，再从所选小组的合格销售中沿用现有权重落人。
需求编号：REQ-ASSIGN-001｜状态：待上传｜更新时间：2026-11-24
需求类型：规则、状态与数据｜补充类型：表单、字段与列表；权限与审计
依赖项目：REQ-ORG-002《CRM组织数据权限二期》
📌
- 配置入口：在现有“分配与掉库设置”内增加“分组规则”页签。
- 分配方式：渠道和目标小组分别支持多选，再从所选小组的并集中按现有销售权重分配。
- 不做：不新增页面、看板、导出、模拟器或其他匹配维度。

目标与范围

目标

让运营按稳定渠道把新线索自动路由到一组目标小组，同时保留现有销售权重、掉库、领取和转派能力。

做

  • 在现有设置面板内按业务线维护渠道到小组的规则，渠道和目标小组分别支持多选。
  • 支持新增、编辑、启用、停用和删除规则。
  • 命中规则后确定目标小组范围，再从所选小组的合格销售中按现有权重分配。
  • 未命中和无接收人时使用明确、可追溯的兜底结果。

不做

  • 不新增菜单、页面或独立规则中心。
  • 不增加规则名称、优先级、说明、生效时间或规则模拟。
  • 不新增第二套人员权重。
  • 不按渠道重新分配已有线索或已有销售归属。
  • 不改变人工领取、重新分配、转派、掉库和付费跟进流程。
  • 不新增指标卡、报表或下载。

业务流程

配置面板

入口与结构

入口：销售管理 → 销售中心 → 分配与掉库设置。

面板顺序：

所属业务线 → 分组规则 / 销售权重 / 掉库规则 → 取消 / 保存

  • 默认打开“分组规则”，业务线默认当前销售中心所选业务线。
  • 三个页签都用同一面板的底部“取消 / 保存”；保存时统一提交当前草稿。
  • 切换业务线、页签或语言时保留未保存的配置。
  • 点击关闭或取消后放弃未保存配置；保存失败时保留草稿并展示错误。
  • 面板不展示规则摘要、业务介绍或效果说明。

分组规则

  • 页签标题右侧提供“新增规则”按钮。
  • 规则表列为：渠道 → 目标小组 → 接收状态 → 启用 → 操作。
  • 新增和编辑使用表格上方的内联表单，不叠加二级弹窗。
  • 内联表单字段顺序为：渠道（多选）→ 目标小组（多选）→ 保存规则 / 取消。
  • 渠道与目标小组均必填；保存单条规则后回到规则表，完整配置仍需点击面板底部“保存”后生效。
  • 面板底部“保存”会先校验并提交当前已填写的内联规则，不会丢弃尚未单独保存的规则表单。
  • 渠道使用可搜索的多选控件，展示渠道名称和稳定 Code；匹配使用稳定 ID/Code，不使用名称。
  • 目标小组复用 REQ-ORG-002 的可搜索、多选组织树组件，并使用“目标小组”模式：
  • 展示当前业务线以及部门、小组层级路径。
  • 仅当前业务线下启用的组级节点可勾选；业务线和部门作为路径节点只用于展开和定位。
  • 支持搜索小组名称或完整路径、清空和一次选择多个小组。
  • 候选节点只来自当前操作人可管理业务线，不因展示路径扩大数据权限。
  • 同一业务线内同一渠道只能存在一条规则；编辑时排除自身后重复则阻止保存。
  • 同一规则可包含多个渠道和多个小组；所选小组共同组成该规则的候选范围。
  • 新规则默认启用。启用开关变更先进入草稿，面板保存后生效。
  • 所选小组均没有合格销售时，接收状态显示“无接收人”，允许保存；运行分配时进入业务线待分配池。
  • 删除规则时在该行内二次确认；取消确认不改变草稿。
  • 无规则时展示空表状态和“新增规则”入口。

销售权重与掉库规则

  • “销售权重”保留一人一行的权重编辑方式，表格列顺序调整为：领取人 → 主组织 → 分配权重 → Email。
  • 主组织只读展示成员在 REQ-ORG-002 中配置的当前主组织完整路径。
  • 权重表上方增加“主组织”筛选，复用组织树组件的搜索和多选能力；选择一个或多个组后，只展示主组织位于所选组的成员。
  • 未选择筛选条件时展示当前业务线全部销售；筛选只影响当前表格展示，不改变人员参与分配的范围或权重。
  • 成员未配置有效主组织时仍可在“全部主组织”下展示为“未配置主组织”，但不能被具体组织筛选命中，也不能接收新线索。
  • 所选主组织下没有销售时展示空态，不展示无归属或无关人员。
  • “分配权重”和 Email 沿用现有字段及权重为 0 不参与分配的规则。
  • “掉库规则”沿用现有开关和“领取后超过 N 分钟无跟进记录”规则。
  • “销售权重”新增主组织列和筛选，其余字段、默认值、分配逻辑和保存权限不变。
  • 目标小组范围确定后，只从主组织直接位于所选任一小组、账号启用、具备销售跟进能力且权重大于 0 的成员中分配。

补充规则：

  • 渠道规则只作用于规则保存成功后新进入未分配态的线索。
  • 同一线索只产生一个成功分配结果；重复或并发请求返回原结果。
  • 一个线索只能有一个当前业务归属小组。
  • 未匹配渠道继续走现有业务线规则，不新增隐藏默认小组。
  • 自动分配只在所选小组范围内选择接收人，不跨到未选小组。
  • 所选小组均无接收人时，线索进入业务线待分配池，并保留命中的规则和所选小组快照用于追溯。
  • 配置保存失败、渠道或小组失效时不改变已保存规则。

异常与边界

  • 无渠道字典：渠道下拉为空，“保存规则”不可用。
  • 无可用小组：“新增规则”仍可打开表单，但目标小组为空且不能保存。
  • 重复渠道：所选渠道中存在已被其他规则使用的渠道时阻止保存，并在渠道字段下提示。
  • 无接收人：允许保存，规则行显示“无接收人”；新线索进入业务线待分配池。
  • 无主组织成员：在“全部主组织”下显示“未配置主组织”，具体组织筛选不命中，也不进入自动分配候选。
  • 筛选无结果：销售权重表显示“当前主组织下没有销售”，权重配置保持不变。
  • 保存失败：面板保持打开并保留全部草稿，提示重试。
  • 并发修改：其他人已先保存时，本次提交提示“配置已更新，请重新加载”，不静默覆盖。
  • 重复分配：按线索分配事件幂等，只保留一个成功结果。
