# 业务术语

| 术语 | 定义 |
|---|---|
| 业务线 | 市场、时区和数据范围的主边界；不再用“国家”作为业务维度名称 |
| 组织节点 | 业务线下的区、部、组，最多四级 |
| 数据授权 | 决定成员可查看和操作哪些本人、组织子树或业务线数据 |
| 个人范围 | 当前操作人本人归属的主对象，以及通过父对象继承的可访问关联记录；本人执行但归属于他人的数据不自动进入个人范围 |
| 组织架构范围 | 当前操作人获授权组织节点及其全部下级；必要祖先只用于定位 |
| 全节点范围 | 当前操作人已获授权的全部业务线和组织节点；不等同于全公司或超级管理员范围 |
| 操作归属 | 操作后数据归属于哪个个人或组织节点；同时记录真实操作人、业务归属和事件时组织快照 |
| 主组织 | 成员在业务线内的唯一行政归属，不自动产生数据权限 |
| 当前业务归属 | 线索当前负责的唯一组织节点 |
| 组织快照 | 事件发生时保存的组织 ID、名称和路径 |
| 首跟 CC | 线索第一次成功分配时的负责人 |
| 首跟承接量 | 首跟 CC 非空的去重 Lead 数 |
