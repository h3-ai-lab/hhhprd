# RAG 检索规则

## 来源优先级

1. 当前项目 `memory/` 中已确认的数据和决策。
2. 当前项目 `rag/sources.yaml` 声明的项目资料。
3. 公共 `shared/memory/` 中的术语、现状和已确认决策。
4. 当前 PRD 和原型。
5. 外部需求文档与 CRM 页面快照。

出现冲突时，优先使用时间更新且证据更直接的数据，并在产物中记录来源。

## CRM 页面快照缺失处理

处理外部需求文档与 CRM 页面快照时，先尝试读取对应的实时 CRM 页面。

- CRM 因登录失效、权限不足、网络异常或页面不可用而无法读取时，立即暂停现状结论，并向用户说明具体页面、访问条件和需要补充的授权。
- 通知用户后等待授权；不得在未通知的情况下直接用产品说明、历史手册或截图替代实时页面快照。
- 用户未授权或确认无法授权时，才检索最新产品说明、使用手册、截图或历史资料作为降级依据。
- 降级资料必须标注为非实时页面快照，只能用于理解产品定位和已有能力，不能据此推断当前字段顺序、筛选器位置、排序能力或实际权限配置。
- 获得授权后重新读取实时 CRM，并以新的页面快照校正此前基于降级资料形成的结论。

## 检索原则

- 先按文件名和关键词缩小范围，再读取相关章节。
- 不把整本手册或全部历史 PRD 一次性加载。
- 事实、规则和决策仅从来源中提取；不要将检索结果自动视为永久记忆。
- 写入 Memory 前必须已确认，并附来源和日期。
